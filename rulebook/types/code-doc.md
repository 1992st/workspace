## Knowledge

- 技术文档优先保证结构导航和可运行示例。
- 每个接口段落应包含输入/输出/错误处理。

## Beautify Dos

- 先给快速开始，再给完整示例。
- 关键参数和限制条件独立成节。

## Beautify Donts

- 不给上下文的碎片化代码块。
- 缺失版本与兼容信息。

## Visual Triggers

- 参数对照可插入对比框。
- 调用步骤可插入步骤流。

## Selfcheck Focus

- 示例是否可复制运行。
- 错误处理描述是否完整。
