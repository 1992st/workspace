## 规则格式

每条规则必须包含：
- **编号**: R001, R002...（唯一，不随版本改变）
- **来源**: 哪本书、哪个原则
- **核心表述**: 一句话规则
- **适用场景**: 什么时候用
- **检查项**: 具体操作前检查什么

## 规则分类

### A. 市场认知（Market Understanding）
### B. 买入纪律（Buying Discipline）
### C. 卖出纪律（Selling Discipline）
### D. 风险控制（Risk Control）
### E. 情绪管理（Emotion Management）
### F. 独立思考（Independent Thinking）

# 投资规则正文

## A. 市场认知

### R001: 华尔街没有新鲜事
- **来源**: 《股票大作手回忆录》P01
- **核心**: 今天发生的一切，以前发生过，以后还会再发生
- **适用**: 任何市场判断前
- **检查**: 当前情况是否与历史某阶段相似？历史后续如何发展？

### R002: 历史会重演
- **来源**: 《股票大作手回忆录》P02
- **核心**: 市场心理和行为的模式会周期性出现
- **适用**: 牛熊判断、泡沫识别
- **检查**: 当前是否出现历史已验证的危险信号？

### R003: 市场永远不会错
- **来源**: 《股票大作手回忆录》P03
- **核心**: 走势与预期相反时，错的是你的判断，不是市场
- **适用**: 持仓亏损时
- **检查**: 我是否在与市场争论？是否该认错止损？

## B. 买入纪律

### R004: 大钱靠坐着赚
- **来源**: 《股票大作手回忆录》P04
- **核心**: 既能判断正确又能稳坐不动的人罕见
- **适用**: 考虑买入时
- **检查**: 是否有明确大趋势？是否准备长期持有？

### R005: 正确时机 > 完美价格
- **来源**: 《股票大作手回忆录》P05
- **核心**: 关键不是在最低价买入，而是在正确时间买入
- **适用**: 择时决策
- **检查**: 趋势是否确认？是否等待回调确认支撑？

### R006: 在牛市中持有
- **来源**: 《股票大作手回忆录》P14
- **核心**: 牛市策略是买入并持有，直到牛市接近结束
- **适用**: 牛市持仓
- **检查**: 是否处于牛市？牛市结束信号是否出现？

## C. 卖出纪律

### R007: 不与行情争论
- **来源**: 《股票大作手回忆录》P06
- **核心**: 行情带反映集体智慧，尊重客观走势
- **适用**: 持仓亏损时
- **检查**: 是否因为主观判断而忽视客观信号？

### R008: 总是卖得太早
- **来源**: 《股票大作手回忆录》P15
- **核心**: 不试图逃顶，提前卖出锁定利润
- **适用**: 盈利持仓
- **检查**: 是否贪婪地等待最高点？利润是否已足够？

### R009: 反弹后卖出
- **来源**: 《股票大作手回忆录》P16
- **核心**: 下跌趋势中，反弹是卖出机会
- **适用**: 熊市/下跌持仓
- **检查**: 这是反弹还是反转？成交量是否配合？

## D. 风险控制

### R010: 亏损是最好的老师
- **来源**: 《股票大作手回忆录》P08
- **核心**: 亏损教会你不该做什么，从而学会该做什么
- **适用**: 每次亏损后
- **检查**: 这次亏损学到了什么？如何避免重复？

### R011: 打败自己的不是市场
- **来源**: 《股票大作手回忆录》P09
- **核心**: 亏损来自自身的贪婪、恐惧、无知和缺乏纪律
- **适用**: 复盘时
- **检查**: 亏损原因是市场还是我自己？

### R012: 判断正确但输光
- **来源**: 《股票大作手回忆录》P10
- **核心**: 方向正确≠交易正确，时机、仓位、风控同样重要
- **适用**: 杠杆/重仓操作前
- **检查**: 即使方向对，仓位是否安全？止损是否设置？

## E. 情绪管理

### R013: 两种情绪：希望与恐惧
- **来源**: 《股票大作手回忆录》P11
- **核心**: 该恐惧时充满希望，该希望时充满恐惧，是人性缺陷
- **适用**: 任何决策时
- **检查**: 当前情绪是否逆向？是否被情绪驱动而非数据驱动？

### R014: 了解你自己
- **来源**: 《股票大作手回忆录》P12
- **核心**: 深刻认识自己的性格弱点，建立适合的交易系统
- **适用**: 建立个人策略时
- **检查**: 这个操作是否符合我的性格？我是否在勉强自己？

### R015: 态度的转变
- **来源**: 《股票大作手回忆录》P13
- **核心**: 从"快速致富"转变为"专业、冷静、纪律化"
- **适用**: 连续亏损后
- **检查**: 我是否在赌？还是在专业地执行系统？

## F. 独立思考

### R016: 对自己判断有信心
- **来源**: 《股票大作手回忆录》P17
- **核心**: 没有对自己判断的信心，无法走远
- **适用**: 面对反对意见时
- **检查**: 这个判断是否基于自己的分析？还是跟随他人？

### R017: 不听消息
- **来源**: 《股票大作手回忆录》P18
- **核心**: 不听内幕、传闻、股评，基于分析形成判断
- **适用**: 听到"消息"时
- **检查**: 这个操作是否基于消息？消息是否已price in？

### R018: 从不同角度研究
- **来源**: 《股票大作手回忆录》P19
- **核心**: 不满足于读带和个股波动，研究宏观、行业、资本流动
- **适用**: 分析框架升级
- **检查**: 是否只看了技术面？基本面、资金面、情绪面是否考虑？

### R019: 赚钱不靠思考
- **来源**: 《股票大作手回忆录》P20
- **核心**: 一旦判断正确，最好的行动是等待，让时间工作
- **适用**: 持仓动摇时
- **检查**: 我是否过度分析？是否因为无聊而操作？

### R020: 学习需要五年
- **来源**: 《股票大作手回忆录》P07
- **核心**: 交易是长期技艺，学费必须用时间和亏损支付
- **适用**: 急于求成时
- **检查**: 我是否期望短期成功？是否有长期学习的心态？

# 规则使用方式

## 作为 System Prompt 拼接

```
【System Prompt 结构】

1. 基础身份定义
2. 投资规则文档（本文件）
3. 分析策略 prompt
4. 当前任务指令

【拼接示例】

你是一位资深股票投资分析师。

【投资规则】（必须遵守）
R001: 华尔街没有新鲜事 - 当前情况是否与历史相似？
R002: 历史会重演 - 是否出现历史验证的危险信号？
...
R020: 学习需要五年 - 是否有长期学习的心态？

【分析任务】
分析股票 {code}，生成投资建议...
```

## 分析时引用格式

```markdown
## 分析结论

### 规则检查
- R004（大钱靠坐着赚）: ✅ 符合 - 处于上升趋势
- R005（正确时机）: ✅ 符合 - 回调至支撑位
- R013（两种情绪）: ⚠️ 注意 - 市场恐慌可能过度

### 操作建议
基于规则检查，建议 BUY...
```

## 复盘时引用格式

```markdown
## 今日复盘

### 规则违反记录
- R007（不与行情争论）: ❌ 违反 - 持仓下跌时未止损
- R010（亏损是老师）: ✅ 符合 - 记录了教训

### 改进措施
- 下次严格执行 R007，设置自动止损
```

## 冲突处理

当新书籍原则与现有规则冲突时：

| 冲突类型 | 处理方式 |
|---------|---------|
| 表述不同，实质相同 | 保留现有，新来源作为补充引用 |
| 视角不同，各有道理 | 标记为"观点A vs 观点B"，分析时根据场景选择 |
| 直接矛盾 | 记录冲突，人工决策，版本升级时注明 |
