# Book Strategy Base

- strategy_version: v2
- scene: stock_analysis
- rule: always apply these global book strategies before generating a trade recommendation

## REM-R001 华尔街没有新鲜事
- snippet: 先找历史相似局面，再判断当前走势是否只是旧剧本的新一轮演绎；没有历史参照时降低确定性。
- check: 当前走势是否对应历史常见阶段？
- check: 相似阶段后来通常如何演化？

## REM-R002 历史会重演
- snippet: 识别重复出现的泡沫、补跌、逼空和退潮模式；看到危险信号时，先考虑风险而不是先找借口。
- check: 是否出现历史验证过的危险信号？
- check: 当前所处阶段是否接近历史高风险区？

## REM-R003 市场永远不会错
- snippet: 当走势和预期冲突时，以价格和量能的现实为准，不要用主观故事对抗市场。
- check: 价格行为是否已经否定原判断？
- check: 我是否在坚持观点而忽视客观走势？

## REM-R010 亏损是最好的老师
- snippet: 输出建议时要能被复盘，明确本次判断依赖哪些证据、失效条件是什么，避免重复犯同一种错。
- check: 这套判断未来如何验证？
- check: 如果错了，最可能错在哪个环节？

## REM-R011 打败自己的不是市场
- snippet: 先排查贪婪、恐惧、冲动和确认偏误，再下结论；很多坏交易不是市场烂，而是执行烂。
- check: 这笔建议是否带有情绪性偏差？
- check: 真正的风险来自市场还是来自执行？

## REM-R012 判断正确但输光
- snippet: 方向判断正确不等于交易正确，所有建议都必须带仓位、止损和失效条件，避免对了方向却输在执行。
- check: 仓位是否和胜率匹配？
- check: 止损和失效条件是否清晰？

## REM-R013 希望与恐惧
- snippet: 识别建议中是否存在该怕不怕、该上不上这种反人性错误；情绪失真时要下调结论置信度。
- check: 是否在该止损时抱有希望？
- check: 是否在该出手时被恐惧压制？

## REM-R014 了解你自己
- snippet: 建议必须考虑执行难度和持仓风格匹配度，不给与用户能力边界明显不匹配的计划。
- check: 这套计划是否适合短线执行节奏？
- check: 用户是否容易在关键节点执行变形？

## REM-R015 态度的转变
- snippet: 把分析写成专业流程，不把交易写成赌博冲动；没有证据门槛就不给高置信度结论。
- check: 本次结论是否基于流程而不是冲动？
- check: 是否遵守数据门槛和纪律？

## REM-R016 对自己判断有信心
- snippet: 所有结论都必须能回到自己的证据链，而不是借市场传闻、常识口号或主观好恶撑场面。
- check: 结论是否基于自己的证据链？
- check: 是否只是重复外部流行观点？

## REM-R017 不听消息
- snippet: 消息只能作为催化剂评估，不得替代数据判断；无法验证或已被 price in 的消息不能当主要买卖理由。
- check: 这条消息是否已被市场消化？
- check: 没有消息时，这笔交易还站得住吗？

## REM-R018 从不同角度研究
- snippet: 至少同时检查市场环境、个股结构、板块映射、基本面和消息面，禁止只靠单一维度下结论。
- check: 技术面、基本面、消息面、市场面是否都看过？
- check: 是否存在单一维度过度主导判断？

## REM-R019 赚钱不靠思考
- snippet: 当趋势和证据已经成立时，减少花哨解释，强调执行、持有和等待；别把分析写成反复摇摆的评论。
- check: 是否已经具备等待而不是反复换手的条件？
- check: 结论是否过度分析、缺少执行重点？

## REM-R020 学习需要五年
- snippet: 把每次分析当成可积累、可验证的长期系统建设，不为短期讨好用户而给虚高把握。
- check: 这次分析是否便于后续复盘学习？
- check: 是否为了给答案而伪装确定性？
