# 投资规则与纪律

## 定位

- 本文档是 Win_Stock 的稳定纪律层，提供长期有效、已相对固化的投资规则
- 它不是所有方法知识的唯一载体
- 书籍提炼、方法探索、候选框架可先保留在 `books/` 归档或方法文档中
- 只有成熟度足够高、适合长期复用的内容，才逐步吸收到本规则文档或运行时策略中

## 核心投资原则（来自《股票大作手回忆录》）

### R001 - 市场永远正确
> "市场永远不会错，只有你的看法会错。"
- 不与市场对抗，趋势是你的朋友
- 当判断与市场走势矛盾时，先怀疑自己的判断

### R002 - 顺势而为
> "不要试图在熊市中抄底，也不要在牛市中逃顶。"
- 确认趋势后再行动
- 趋势不明时保持观望

### R003 - 截断亏损，让利润奔跑
> "亏损的头寸不要加仓，盈利的头寸不要轻易了结。"
- 严格止损，亏损不超过本金的 5%
- 盈利头寸让利润充分发展

### R004 - 不要频繁交易
> "频繁交易是亏损的根源。"
- 等待高确定性机会
- 质量 > 数量

### R005 - 独立思考
> "不要听信内幕消息，不要跟风。"
- 基于自己的分析做决策
- 市场情绪极端时反向思考

### R006 - 保持耐心
> "机会是等出来的，不是追出来的。"
- 没有好机会时空仓等待
- 不因为无聊而交易

### R007 - 记录交易
> "记录你的每一笔交易，分析你的错误。"
- 详细记录买入卖出理由
- 定期复盘交易记录

### R008 - 不要摊平亏损
> "亏损的头寸不要加仓摊平成本。"
- 亏损说明判断可能错误
- 加仓亏损头寸是错误加倍

### R009 - 关注大盘
> "大盘走势影响 80% 的股票。"
- 分析个股前先判断大盘环境
- 大盘系统性风险时降低仓位

### R010 - 只交易活跃股票
> "不要交易冷门股，流动性是生命线。"
- 选择成交量充足的股票
- 避免流动性陷阱

## 量价分析纪律（来自《量价分析：威科夫的盘口解读方法》）

### V001 - 三步分析法
> 微观→宏观→全局：所有 K 线分析必须明确标识所用级别。
- **微观级别**（操作周期的 1/5 级别 K 线）：判断单根 K 线与成交量的关系是"确认"还是"异常"
- **宏观级别**（操作周期 K 线）：寻找小级别趋势或反转
- **全局级别**（高一级别 K 线）：定位当前在长期趋势中的位置
- 三级别一致 → 信号置信度高；全局级别与微观级别矛盾 → 放弃本次操作

### V002 - 等待确认，不抢跑
> 信号出现后，等待至少一根 K 线确认，不提前介入。
- 看到缩量企稳信号，等下一根 K 线不创新低再行动
- 看到放量突破信号，等回踩确认不破再买入
- 基于《量价分析》核心启示：市场如同巨型油轮，不会嘎然停止又迅速启动

### V003 - A 股缩量优先
> 在 A 股，缩量信号的可信度始终高于放量信号。
- **原因**：主力可能通过对倒制造虚假放量，但无法伪造缩量状态（伪造缩量的成本无限高）
- 缩量（成交量 < 前 5 日均值的 50%）+ 价格企稳 → 可信信号
- 放量 + 负面因子暴露（高估值/高波动）→ 低置信度，宁可放弃
- 放量 + 正面因子暴露（低估值/强盈利）→ 中等置信度，需结合大单流向交叉确认

### V004 - 因果定律：蓄势充分才出手
> 横盘时间与突破强度正相关。
- 横盘整理 < 5 根 K 线的突破 → 不追，蓄势不充分
- 横盘整理 5-20 根 K 线的突破 → 正常参与
- 横盘整理 > 20 根 K 线的突破 → 高置信度参与
- "Effort vs Result"检验：放量但价格不涨（努力无结果）→ 异常信号，警惕对倒/派发

## 因子投资纪律（来自《因子投资：方法与实践》）

### F001 - 因子扫描前置
> 分析个股前必须先回答该股的因子暴露情况。
- 确定该股票在规模（大盘/中盘/小盘）、价值（低估/高估）、盈利（强/弱）、波动（高/低）四个核心维度上的暴露
- 判断这些因子在当下的市场表现阶段（强势期/弱势期/转折期）
- **结论**：因子有利 → 增强量价信号；因子不利 → 削弱量价信号
- 示例：缩量企稳出现的股票同时是低估值+强盈利 → 坚定买入；缩量企稳的股票是高估值+弱盈利 → 不确定，等待更明确信号

### F002 - 不迷信因子溢价
> 因子溢价有时效性，过去 20 年的回测不等于未来 1 年的表现。
- 不因为某因子历史上有效就认为它永远有效
- A 股中相对更稳健的因子组合：**低波 + 盈利 + 质量**（区别于动量或价值的周期性大幅衰退）
- 任何被市场"共识化"的因子策略，其超额收益都会因拥挤而衰减
- 多重假设检验警示：t 值 < 3.0 的因子大概率是数据挖掘产物，不应作为核心依据

### F003 - 行为偏差自查
> 每次下结论前检查是否存在认知偏差。

**自检清单**（按重要性排序）：
- **近因偏差（Recency Bias）**：最近N日涨跌幅偏离多少σ？若偏离度>1.5σ，近因偏差风险高，必须下调信心，同时查一下均值回归数据——60日K线中有几次这样的偏离，后续如何演变。
- **统计极端封顶规则**：
  - 3日涨跌幅偏离>1.5σ 或 RSI偏离>1.5σ → 置信度封顶65%
  - 3日涨跌幅偏离>2.0σ 或 RSI偏离>2.0σ 或 布林带宽偏离>2.0σ → 封顶60%
  - 3日涨跌幅偏离>3.0σ → 封顶50%
  - 任何两项同时>2.0σ → 封顶40%
- **叙事偏差**：是否先定义了结论再找数据支持？在分析输出中标注
- **行动偏差**：是否存在为了提供操作指令而勉强下结论的情况？"观望/等待"也是有效建议。
- **单框架套用偏差**：分析框架是否直接套用了其他板块/个股的模式而不适用于当前标的？
- **大盘配合检查**：个股方向与大盘方向相反时，逆势操作需要更强证据，否则置信度下调一级。
- 发现以上任一偏差 → 自动下调结论置信度一档（10-15点），并标注偏差类型和下调幅度

## 交叉验证与框架纪律（双书融合）

### X001 - 双框架一致性检验
> 因子信号与量价信号必须交叉验证，不一致时不得给高置信度。
- **一致**：因子方向 + 量价方向指向同一结果 → 置信度 75%+
- **不一致**：因子看多但量价看空，或反之 → 置信度 < 50%，必须在分析中明确标注分歧原因
- **框架自身失效**：市场环境异常或明确信号缺失 → 坦率说"不确定，建议等待"（R006 保持耐心）
- 这个检验是整个分析流程的"安全带"——防止单一框架的偏见主导决策

### X002 - 市场可操作等级
> 根据大盘环境综合评估当前是否适合操作。
- **★☆☆☆☆（不可操作）**：大盘趋势向下 + 涨跌家数比 < 0.3 + 系统性风险（政策突变/流动性危机）
  → 暂停所有分析结论输出，只建议减仓或空仓
- **★★★☆☆（正常操作）**：大盘震荡或温和上涨，无明显系统性风险
  → 正常执行分析流程
- **★★★★★（高可操作）**：大盘趋势向上 + 资金持续流入 + 赚钱效应好
  → 可适当提升仓位，增加交易频率
- 市场可操作等级必须写在每次分析的开头

### X003 - 持仓周期匹配
> 使用的方法必须与持仓周期对齐，不可混用。
- **短线操作（日线级别）**：只用量价分析做决策，不基于因子判断做短线操作
- **中线持仓（周月级别）**：用因子暴露决定配置方向，不因单日量价噪音轻易下车
- **模糊地带（数周至数月）**：两种方法同时失效的概率最高。在此区间内，只使用最保守的信号——要求因子与量价信号**同时极端一致**才行动
- 每次分析输出时，必须声明本次分析适用的"持仓周期范围"

### X004 - 反脆弱设计
> 单一框架不可靠，多框架独立验证才是防御的核心。
- 任何单一框架（无论是量价还是因子）给出的信号，单独看都只是"猜测"
- 只有当两个逻辑独立的方法给出相同信号时，才构成"证据链"
- 证据链强度 = 信号数量 × 框架独立性 × 一致性程度
- 核心宗旨：不追求每次预测都准确，追求在不确定的环境中做大概率正确的决策

## 做T纪律

### T001 - 有底仓才能做T
- 没有持仓不做T
- 底仓是安全垫

### T002 - 做T仓位控制
- 单次做T不超过底仓的 50%
- 保留足够底仓

### T003 - 做T止损
- 做T失败立即止损
- 不将做T变成加仓

### T004 - 不做逆势T
- 下跌趋势不做正T
- 上涨趋势不做反T

### T005 - 控制做T频率
- 同一只股票每日最多做T 2 次
- 频繁做T增加错误概率

## 仓位管理规则

### P001 - 总仓位控制
- 单只股票不超过总资金的 30%
- 总仓位根据市场环境调整

### P002 - 分仓买入
- 首次建仓不超过计划仓位的 50%
- 确认趋势后加仓

### P003 - 止损纪律
- 单笔亏损不超过本金的 5%
- 触及止损无条件执行

## 分析规则合规检查

每次分析结论必须引用相关规则编号：

```
分析结论示例：

【市场可操作等级】★★★☆☆（正常操作）【X002】

【操作】BUY
【置信度】75%
【适用周期】日线级别（短线）【X003】
【依据】
- 缩量企稳 + 下根 K 线确认不创新低（V001, V002）
- 低波 + 盈利暴露正面，因子当前处于强势期（F001）
- 双框架一致：量价看多 + 因子看多 → 高置信度（X001）
- 个股处于周线级别超卖，因果定律蓄势充足（V004）

【风险提示】
- 止损 15.80（R003 截断亏损）
- 仓位 3 成（P001 总仓位控制）
- 行为偏差检查：无显著偏差（F003）
```
