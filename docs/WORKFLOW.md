# 工作流程设计 - AI-Stock-Pro

## 1. 定时任务设计

### 1.1 每日任务时间表

```
时间          任务                        优先级    超时处理
─────────────────────────────────────────────────────────
09:00        盘前新闻扫描                  高        跳过，记录日志
09:15        大盘环境分析                  高        使用昨日分析
09:30        开盘监控（可选）              低        -

14:50        获取当日行情数据              高        延迟15分钟重试
15:00        收盘数据确认                  高        延迟15分钟重试
15:30        生成个股分析报告              高        延迟1小时重试
16:00        记录当日预测                  高        标记为延迟
16:30        验证昨日预测                  中        次日补验证

03:00        数据库备份                    低        次日重试
```

### 1.2 每周任务

```
周一 09:00    上周预测复盘报告              中
周五 16:30    下周策略规划                  低
周日 03:00    数据归档和清理                低
```


```
  │
  ▼
┌─────────────────┐
```

```
│ 2. 通知管理员    │
│ 3. 启动重试机制  │
└────────┬────────┘
         │
         ▼
重试次数 < 3?
  │
  ├─ 是 ──▶ 等待 5 分钟 ──▶ 重试数据源A
  │                           │
  │                           ▼
  │                      成功? ──▶ 继续流程
  │                           │
  │                           否
  │                           │
  │                           ▼
  │                      重试次数 + 1
  │                           │

         │

         ▼

         │
         ▼
```

## 4. 并发控制设计

### 4.1 数据获取并发

```python
# 使用异步和限流
async def fetch_all_stocks(stock_list: List[str]):
    semaphore = asyncio.Semaphore(5)  # 最多5个并发
    
    async def fetch_with_limit(symbol):
        async with semaphore:
            return await fetch_stock_data(symbol)
    
    tasks = [fetch_with_limit(s) for s in stock_list]
    return await asyncio.gather(*tasks, return_exceptions=True)
```

### 4.2 LLM 调用并发

```python
# LLM API 通常有 RPM 限制
llm_rate_limiter = RateLimiter(
    requests_per_minute=20,  # 根据 API 限制调整
    burst_size=5
)

async def analyze_with_llm(prompt):
    async with llm_rate_limiter:
        return await llm_client.analyze(prompt)
```

## 5. 监控与告警

### 5.1 关键指标监控

| 指标 | 检查频率 | 告警阈值 | 告警方式 |
|------|---------|---------|---------|
| 数据获取成功率 | 每次任务 | < 95% | 日志+飞书 |
| LLM API 成功率 | 每次任务 | < 90% | 日志+飞书 |
| 任务执行时间 | 每次任务 | > 30min | 日志 |
| 预测验证率 | 每日 | < 90% | 日志 |
| 系统准确率 | 每周 | < 50% | 飞书 |
| 磁盘使用率 | 每日 | > 80% | 日志 |

### 5.2 告警分级

```
🔴 CRITICAL (立即处理)
   - 数据库连接失败
   - 核心任务连续失败 3 次
   - 磁盘空间不足

🟡 WARNING (24小时内处理)
   - 数据源切换
   - LLM API 降级
   - 单只股票分析失败

🟢 INFO (记录即可)
   - 任务正常完成
   - 使用缓存数据
   - 轻微延迟
```
