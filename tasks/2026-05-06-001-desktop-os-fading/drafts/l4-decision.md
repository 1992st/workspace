### 🥇 选题卡 A：桌面正在消失，Windows 是最后一个扛旗的

**topic_id:** desktop-is-fading
**受众：** 科技行业从业者、企业 IT 决策者、对 OS 格局感兴趣的普通读者
**核心冲突：** Windows 在桌面端依然称霸（65-72%），但衡量市场的方式变了——全设备口径下 Windows 仅剩 27%。桌面本身在缩。
**证据链：**
- 美国全设备 Windows 31.65%，桌面仅为移动设备的一半
- 中国 Android 36.6% 几乎追平 Windows 36.19%
- 全球 Android 44% > Windows 27%，iPhone 18% 接近 macOS 的 6%
- Gartner 预测 $500 以下 PC 2028 年前消失
- 微软早已不是"Windows 公司"——Azure 收入 > $750 亿，Windows OEM 持续下滑
**why_now:**
- 微软 Q3 2026 财报刚刚发布（2026.4.29），Windows 数据新鲜
- Gartner/IDC/Counterpoint Q1 2026 PC 数据集中释放
- Google I/O 刚开，Android 生态在桌面化（Desktop Mode）
**风险：**
- "PC 已死"话题不够新，2013 年就说过了
- 需要区分"PC 市场萎缩" vs "桌面操作系统份额变化"——两者不完全是一回事
**化解：** 不走"PC 死了"的老路，走"战场变了"的新角度。用全设备口径数据作为"电梯投炸弹"的开场。
**三条可执行动作：**
1. **企业 IT 决策者：** 重新评估设备采购策略——如果不强制需要 Windows 独占软件，Mac 和 Chromebook 的 TCO（总拥有成本）已具竞争力
2. **开发者：** 跨平台适配优先级需调整——移动端不再是"附加"，桌面端不再是"默认"
3. **个人用户：** 关注 OS 生态绑定成本——如果所有设备都在同一生态（Apple/Goolge/Microsoft），切换成本远高于直觉

### 🥈 选题卡 B：macOS 涨了 5%，花了 7 年——为什么 Mac 还是干不过 Windows？

**topic_id:** mac-vs-windows-why-so-slow
**受众：** 果粉、技术爱好者、产品经理
**核心冲突：** Apple Silicon 被公认为笔记本领域的最佳硬件，M 系列芯片 7 年迭代到 M5，Mac 出货跑赢大盘（+9% vs +2.5%），但 macOS 份额从 9% 只涨到 14-16%。为什么？
**证据链：**
- Apple Silicon 的压倒性性能/续航优势
- Mac 在美国桌面市场达 29.62%
- Mac 企业份额在涨（US 企业 ~11%，涨 11.2%）
- 但全球桌面 macOS 也就 15%
- 原因：Windows 的企业 IT 锁定效应 + 游戏生态缺失 + 中国等市场的低占有率
**why_now:**
- Tim Cook 财报会上说 Mac 需求超供给，AI 驱动 Mac 换机
- 数据窗口期（IDC Q1 2026）
**风险：**
- 容易写成"Mac 真好，消费者眼瞎"的营销文
- 增长数据不够戏剧化
**化解：** 不写"谁更好"，写"生态锁定如何打败产品力"——产品思维和商业思维的差距。
**三条可执行动作：**
1. **产品经理：** 产品好 ≠ 市场赢，生态锁定效应是最大的竞争护城河
2. **想要转 Mac 的用户：** 先检查你常用软件是否有 Mac 版，确认 IT 支持成本
3. **开发者：** 如果你的目标用户是开发者/设计师，优先适配 macOS；如果是大众用户，先做 Windows

### 🥉 选题卡 C：Chromebook 崩了，谁接盘教育市场？

**topic_id:** chromebook-crash-education-shift
**受众：** 教育从业者、硬件厂商、政策研究者
**核心冲突：** ChromeOS 出货预计 2026 年跌 27.6%（The Register），Chromebook 上半年销量崩塌 66%。但教育市场有 93% 的美国学区还在买 Chromebook。这中间出了什么问题？
**证据链：**
- ChromeOS 在 Statcounter Unknown 19.28% 中可能占大头
- 单纯的教育笔记本市场在缩（线上教育红利退潮）
- Chromebook 生命周期短（3-4 年换一次）的问题正在暴露
- 高端教育开始向 Mac 转移
- 微软 Windows 11 SE 已死，没人接盘
**why_now:**
- 2026 年返校季即将到来，教育采购窗口期
- Google 刚在 Google I/O 更新了 ChromeOS
- 内存/存储涨价重创低价设备市场
**风险：**
- 角度太窄（教育市场），传播面不如 A/B 宽
- 中国市场不关心 Chromebook
**化解：** 只能做成行业分析，不做大众传播。
**三条可执行动作：**
1. **教育采购决策者：** 如果学区 Chromebook 进入换机周期，考虑 Mac 或 Windows 替代方案
2. **硬件厂商：** 教育设备需要拉长生命周期，否则成本难以回收
3. **政策研究者：** 数字教育设备采购不能只拼低价，使用成本和生命周期成本更重要

---

## 推荐选择：🥇 选题卡 A

**理由：**
1. 角度最独特——不是"Windows vs Mac"，是"桌面 vs 移动"。全设备口径数据是真正的"数据炸弹"。
2. 传播面最广——不管用什么设备的人都关心这个话题。
3. 三层受众都能找到共鸣点（企业/开发者/个人）。
4. 数据时效性最优，微软和 IDC 数据都是过去两周内发布的。
5. 与"Agent 小茶馆"的定位匹配——讲的是计算范式的迁移。

**触发条件：** 立即发布，不等到某个事件节点。
