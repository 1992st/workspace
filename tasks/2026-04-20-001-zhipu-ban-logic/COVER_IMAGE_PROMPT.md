## 封面图片提示词

### 中文提示词（发给Kimi）

```
一幅中国风水墨风格的插画，主题为"AI三国志"。

画面构图：
- 中央是一座宏伟的古代城池，城门上写着"荆州"二字，城池被光芒环绕，象征AI技术的光芒
- 城池前方站着两位身穿汉服的谋士/将领，一左一右，背对观众看向远方
- 左边人物手持羽扇（象征诸葛亮式的智谋），右边人物手持长剑（象征武将的战斗力）
- 两人中间悬浮着一个发光的芯片/晶体，象征AI大模型的核心技术
- 城池周围有淡淡的云雾，云中隐约可见代码流和二进制数字（0和1）飘浮
- 背景是淡墨色的山水，远处有现代化的数据中心的剪影

色调：
- 主色调：水墨灰、青黛色、淡金色
- 城池光芒：淡青色和淡金色的光晕
- 芯片：发出淡蓝色的科技光芒

风格：
- 中国传统水墨画 + 现代科技感
- 既有三国历史的厚重感，又有AI未来的科技感
- 画面要有留白，符合中国画的意境
- 整体氛围：史诗感、悬念感、科技与人文的融合

文字（如果需要在画面上）：
- 画面上方或下方留白处可以加上标题"AI三国志·智谱篇"，字体用书法体
- 或者不加文字，保持画面纯粹

要求：
- 16:9宽屏比例
- 适合作为公众号/文章封面
- 画面要有层次：前景人物、中景城池、远景山水
- 整体要高级、有质感，不能太卡通
```

### 使用建议

如果Kimi生图效果不好，可以分段发：
1. 先发场景描述（城池+人物+芯片）
2. 再发色调和风格要求
3. 最后发比例和文字要求

或者试试精简版：
```
水墨风插画，三国城池"荆州"被科技光芒环绕，两位汉服谋士背对观众，中间悬浮发光AI芯片，背景云雾中有二进制代码，色调灰青金，16:9，高级质感
```
