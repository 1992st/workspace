# AI三国志·系列设计

> 用三国人物的性格、命运和博弈逻辑，映射中国LLM厂商的真实处境。不是简单的标签贴牌，而是找到**性格上的同构性**——为什么这个人会这么干？为什么这家公司会这么选？

---

## 一、系列立意

中国LLM赛道正在经历自己的"东汉末年"——群雄并起、资本乱战、格局未定。用三国叙事来写，不是为了好玩，是因为：

1. **三国人物的困境，和LLM厂商的困境高度同构**：地盘、粮草、人才、人心，一样的配方
2. **读者对三国人物有直觉认知**，不用科普背景，省掉大量解释成本
3. **每个人物的结局已定**，可以借古喻今，但不说死——毕竟AI这出戏还没演完

**核心规则**：每章只写一个厂商，不提前剧透其他厂商对应谁。让读者自己猜，制造悬念和讨论空间。

## 三、篇章规划

### 已发布/已写
- **第一章**：智谱 = 坐拥荆州，是刘表还是刘备？（**本篇**）
  - 核心冲突：守成 vs 进取，得民心 vs 防用户
  - 悬念：智谱最终走向刘表的结局，还是刘备的逆袭？

### 待写篇章（建议顺序）

**第二章：DeepSeek = 吕布**
- 核心叙事：战斗力第一，但出身草莽。幻方量化背景=并州军，开源激进=三姓家奴式的反复。不按套路出牌，让所有人措手不及。
- 关键场景：DeepSeek V3/R1发布时的"闪击战"，行业震动
- 悬念：吕布最终死于白门楼。DeepSeek的草莽打法，能持续多久？

**第三章：字节跳动 = 曹操**
- 核心叙事：枭雄。豆包+火山引擎+剪映+抖音，生态全栈推进。不急着亮底牌，每一步都在算。
- 关键场景：字节的AI布局不是单点，是矩阵。曹操的屯田制=字节的流量变现
- 悬念：曹操最终统一北方。字节会不会统一中国AI？
- **注意**：第三章揭晓"曹操位"，回应第一章的悬念

**第四章：月之暗面(Kimi) = 孙权**
- 核心叙事：江东自立。杨植麟年轻，长文本是"长江天险"。守成有余，但开疆不足。
- 关键场景：Kimi的200万字长文本="据长江而守"，但北伐（通用能力）始终没突破
- 悬念：孙权一辈子没出过江东。Kimi会不会永远困在长文本里？

**第五章：百度 = 袁绍**
- 核心叙事：四世三公。中国AI老牌贵族，资源最多，但决策最慢。内部派系=河北士族 vs 颍川士族。
- 关键场景：文心一言发布会 vs 官渡之战。资源碾压但输了人心。
- 悬念：袁绍官渡大败。百度的AI叙事，会不会也输在"决策慢"上？

**第六章：阿里 = 董卓**
- 核心叙事：老牌帝国，霸道。通义千问+阿里云+电商，全栈推进。但内部臃肿，不得人心。
- 关键场景：阿里的AI战略="废立天子"，想定行业标准，但开发者不买账
- 悬念：董卓死于吕布之手。阿里会不会被自己的"吕布"（内部创新）反噬？

**第七章：腾讯 = 司马懿**
- 核心叙事：后发制人。混元大模型不声不响，但微信生态+游戏场景=隐忍蓄力。
- 关键场景：司马懿装病=腾讯AI低调，一旦出手就是高平陵之变
- 悬念：司马懿最终篡魏。腾讯的AI后发优势，能不能变成终局优势？

**第八章：百川智能 = 诸葛亮**
- 核心叙事：谋士。王小川的战略眼光=隆中对，但缺兵马（算力）和粮草（资金）。
- 关键场景：百川的"搜索+AI"战略=联吴抗曹，但独木难支
- 悬念：诸葛亮六出祁山而无功。百川的算力之困，会不会成为永远的遗憾？

**第九章：MiniMax = 马超**
- 核心叙事：西凉猛将。语音/视频多模态=西凉铁骑，战斗力强。港股上市=正式编入伍。
- 关键场景：MiniMax的多模态能力="潼关之战"，一度让曹操（字节）狼狈
- 悬念：马超最终归降刘备。MiniMax会不会被某家大厂收购？

**第十章：零一万物 = 孔融**
- 核心叙事：名士。李开复的海归声望=孔融让梨的美名，但实际地盘小、兵马少。
- 关键场景：零一万物的Yi模型="建安七子"的文学才华，但挡不住曹操（字节）的大军
- 悬念：孔融被曹操所杀。零一万物的名士路线，在硬实力面前能撑多久？

## 四、每章固定结构

为了系列感，每章统一结构：

```
# 标题：[厂商] = [人物]：[核心冲突]

> 开场白：一句话定调，点出这个人物的特质

## 一、[人物]的[核心资源]：[厂商]的家底
- 家底有多厚？（融资、估值、产品）
- 但家底厚不代表赢

## 二、[人物]的[内部问题]：[厂商]的权力结构
- 股权穿透 / 核心团队 / 内部矛盾
- 用三国人物的内部困境做对照

## 三、[人物]的[外部依赖]：[厂商]的供应链/生态
- 供应商 / 合作伙伴 / 渠道
- 粮草命脉掐在谁手里？

## 四、[核心冲突场景]：[厂商]的标志性事件
- 用三国故事的场景来写厂商的真实事件
- 制造情绪共鸣

## 五、[人物]的命运启示：[厂商]的未来走向
- 这个人物的结局已定，但厂商的结局未定
- 留悬念：它会重蹈覆辙，还是逆天改命？

## 最后说几句
- 个人观点，口语化，有态度
```

## 五、悬念设计

**跨章悬念**：
1. 第一章不提曹操是谁，只说"某厂商""大军压境"——让读者猜
2. 第三章揭晓"曹操=字节"，回应第一章的悬念
3. 每章结尾留一个"这个人物的结局是XX，这家厂商会不会也一样？"

**人物命运悬念**：
- 吕布（DeepSeek）最终死于白门楼 → DeepSeek的草莽打法能持续多久？
- 董卓（阿里）死于吕布之手 → 阿里会不会被内部创新反噬？
- 袁绍（百度）官渡大败 → 百度的资源碾压会不会输给人心？
- 孔融（零一万物）被曹操所杀 → 名士路线在硬实力面前能撑多久？

## 六、系列运营建议

**发布节奏**：
- 每章间隔3-5天，保持热度
- 发布顺序：按人物出场顺序（先刘表/吕布，后曹操，再孙权...）
- 每章结尾加一句："下一章，说说那个横扫千军的狠角色。"

**互动设计**：
- 每章结尾让读者猜"曹操是谁""孙权是谁"
- 评论区引导："你觉得Kimi更像孙权还是周瑜？"
- 系列完结后做一个"AI三国志·英雄榜"总结图

**风险提示**：
- 某些类比可能引发厂商不适（如董卓=阿里），需要斟酌措辞
- 吕布=DeepSeek的"三姓家奴"暗示需谨慎，避免冒犯
- 每章免责声明："本文仅为个人分析，不构成投资建议"
