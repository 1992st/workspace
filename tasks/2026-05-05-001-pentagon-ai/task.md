## 事件核心

2026年5月1日，美国国防部宣布与8家科技公司签署机密AI部署协议，允许其AI技术进入IL6/IL7级别的机密军事网络。

### 签约公司（8家）
1. **OpenAI** — ChatGPT / API 进入 GenAI.mil 生态
2. **Google** — Gemini 模型 + 云端AI
3. **NVIDIA** — GPU基础设施，同意不设置超出法律的使用限制（含自主武器）
4. **Microsoft** — Azure Government + 政府云
5. **AWS** — 政府云端 + 多云架构
6. **SpaceX** — 卫星网络 + 前线通信
7. **Reflection AI** — 前沿AI新创
8. **Oracle** — （新浪财经确认加入，部分媒体未提及）

### 被排除的公司
- **Anthropic** — 因拒绝放宽自主武器和大规模监控的安全护栏，被列为"供应链风险"，已进入诉讼

### 关键数据
- 已有 **130万+** 国防部人员使用 GenAI.mil 平台
- 5个月内，任务耗时从"数月缩短到数天"
- NVIDIA协议：不设超出美国法律外的任何使用限制，含自主武器开发
- 五角大楼目标：构建"防止AI供应商锁定"的架构
