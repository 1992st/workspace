# 说个反常识的：AI 记不住你，不是 Prompt 的问题

很多人没意识到一件事：

你跟 ChatGPT 聊了 20 轮，它"记得"你，其实是假象。

每次你发新消息，系统只是把整段对话重新塞给模型。换个窗口、换个会话，它立刻归零。

这不是 Prompt 写得不好，而是 **LLM 天生没有记忆**。

最近我实测了一个框架叫 **OpenClaw**，它解决的就是这个底层问题。

---

## 金鱼脑真相

LLM 的默认状态叫 **Stateless（无状态）**。

大白话就是：它每处理一条消息，都是从头开始认识你。你感觉有连续感，是因为聊天界面在"伪造"连续性。

所以这些场景才会反复出现：
- 让它参考"上周那份方案"，它一脸懵
- 换个窗口，之前调教好的语气全没了
- 想让它主动查个数据、发个邮件？根本做不到

**问题不在模型，而在上下文管理没做好。**

---

## OpenClaw 怎么串起来的？

四个字：**Inject → Assemble → Extend → Persist**

### 1. Inject：给 AI 发入职手册
你一开口，系统就往 LLM 里塞东西：
- **AGENTS.md**：它是谁、负责什么
- **SOUL.md**：该怎么说话
- **TOOLS.md**：能调用什么工具
- **MEMORY.md**：你的偏好和历史记录

**一个 4 字的提问，背后可能注入了 8 万字的系统上下文。** 相当于提前给 AI 写好了入职手册，不用每次都重新交代"你是谁我是谁"。

### 2. Assemble：像流水线一样拼 Prompt
不是手写 Prompt，而是自动拼装出一份「导演通知单」：
- 35% 硬编码规则（安全、执行策略、定时任务）
- 40% 项目上下文（上面那些文档）
- 25% 动态环境（当前时间、模型配置、沙盒状态）

拼完再发给 LLM，保证每次输入都是稳定、可控的。

### 3. Extend：可插拔的工具抽屉柜
想让 AI 查天气、发 GitHub PR、分析股票？

OpenClaw 的做法是挂载 **Skills（技能包）**。每个 Skill 就是一份 `SKILL.md` 规范文档，AI 匹配到之后必须先读取、再执行。

相当于给 LLM 配了一个可插拔的工具抽屉柜，想用哪个拉哪个，不用改一行代码。

### 4. Persist：真正的长期记忆
对话结束后，关键信息自动写入 `MEMORY.md`。

下次再聊，系统会**先检索记忆**，把你之前的偏好、失败记录、持仓股票都找回来。不是伪造连续，是真的记得你。

## 我上周跑的一个真实场景

我用它搭了一个 **AI 股票助手**，测试请求只有 6 个字：

> "分析一下歌尔股份"

OpenClaw 同时激活了 4 个子系统：
- **Bootstrap**：注入选股策略 + 风险偏好
- **Skills**：命中 `stock-api`，自动拉取实时行情、板块热度、资金流向
- **Memory**：检索自选股列表和历史分析记录
- **System Prompt**：把「大盘→板块→新闻→个股」四阶段分析流程拼进 Prompt

然后系统自己跑完四个维度评分，输出一份完整的投资报告：总分、操作建议（BUY/HOLD/SELL）、目标价、止损价，连分批建仓/减仓策略都写好了。

**6 个字进去，一篇报告出来。**

---

## 三条可以今晚就试的动作

1. **如果你在用 AI 做重复工作**：整理一份自己的「角色设定文档」，每次对话前贴进去，观察输出稳定性的变化。
2. **如果你在做 Agent 产品**：别卷 Prompt 了，去卷「上下文注入和拼装 pipeline」的可控性。
3. **如果你纯好奇**：理解「无状态 LLM」和「有状态 Agent」的区别，这会是未来一年的核心分水岭。
