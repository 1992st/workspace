# AI长期记忆准确率不到20%：剑桥大学ATM-Bench测试解读

> 研究人员花了4年时间，给AI造了一个真实的"数字人生"，然后考了它一场记忆测试。结果最聪明的AI，也只考了不到20分。

---

你有没有过这种经历？

跟Claude聊了十几次，每次开头它都亲切地问你"今天想聊什么"——好像你们从来没认识过。跟ChatGPT吐槽过老板，下次它还在给你推荐"如何与上司沟通"的模板。跟Gemini交代了一整段代码逻辑，过了几轮对话它突然问你"这段代码是做什么的"。

你感到一阵熟悉的无力感：它，又忘了。

这不是你的错觉。4月20日，剑桥大学机器智能实验室甩出了一份硬核报告，给整个AI行业当头一棒：当前最先进的AI助手，在"记住你"这件事上，**准确率不到20%**。

这个测试基准叫ATM-Bench，全称很长不用记（"According to Me: Long-Term Personalized Referential Memory QA"），用人话说就是：**研究人员花了4年时间，给AI造了一个真实的"数字人生"，然后考它能不能像人类一样回忆过去。**

注意，这里考的不是"记住刚才聊了什么"，而是"记得你去年做了什么"。

---

## 一、4年"数字人生"，AI考了不到20分

为了让考试足够真实，剑桥大学的研究团队下了血本。

他们收集了**一个真实个体4年的完整数字生活记录**：6741封邮件、3759张照片、533个视频，加起来超过**1.2万个记忆片段**。这些记忆跨越工作、旅行、社交，地理范围覆盖多个国家。就像给一个人建了完整的数字档案馆，每份文件都保留了时间、地点和关联信息。

基于这个庞大的记忆库，研究团队设计了**1038个问答对**。

这些问题不是简单的"找文件"，而是模拟真实场景下人类会怎么回忆。比如：

- "我在葡萄牙旅行期间的酒店费用总共是多少？"——需要找到预订邮件、最终账单，还要判断以哪个为准。
- "Grace是谁？"——照片里出现过这个名字，但Grace可能是宠物、朋友，也可能是家人，需要结合上下文推断。
- "我在那家餐厅吃了什么？"——餐厅名字只在邮件里，照片没有GPS标签，需要跨模态关联才能回答。

最狠的是"困难版"测试集：每个问题平均需要**6.3个不同的记忆片段**才能回答，而且这些片段来自邮件、照片、视频等不同来源，彼此可能还存在矛盾。

然后，研究团队把市面上**5个最先进的AI记忆系统**拉来考试，包括A-Mem、Mem0、HippoRAG等。还给它们配上了GPT-4、Claude Opus 4.6、Codex等顶级大模型。

结果？

**困难版：最好的一家，准确率不到20%。**

**标准版：最好的一家，勉强摸到50%。**

就算是 Claude Code + Opus 4.6，也只考了**33.8%**。Codex最高，也才**39.7%**——连及格线都没到。

这意味着什么？你用了4年的AI助手，它连你去年给妈妈买的相机都记不住。它分不清你的旅行账单哪笔是哪笔，不知道你照片里那个"Grace"到底是谁。

**这不是某个产品不行，是整个行业都不行。**

## 二、为什么AI这么健忘？三个"记不住"的死穴

这个测试最厉害的地方，是精准定位了AI记忆的三个死穴。不是说AI不够聪明，而是它的"记法"和人脑根本不一样。

### 死穴一：个性化指代解析——"你说的Grace，是哪个Grace？"

人类聊天时，很少说"2023年3月15日下午2点我和张三在星巴克喝咖啡"。我们会说"上次和Grace去的那家咖啡店"，然后对方就知道Grace是谁、哪家店、大概什么时候。

但AI呢？如果照片里有三只叫Grace的猫、一个Grace的朋友、还有 Grace Kelly 的电影海报，它根本不知道你说的是哪个。ATM-Bench的测试显示，这种"指称歧义"是AI丢分最多的题型之一。

### 死穴二：多证据冲突——"预订说800，账单说950，信谁？"

人类记忆有个天然机制：当信息矛盾时，优先采信最新、最权威的那个。比如你先在邮件里预订了一个酒店（800元），后来改了预订（950元），最终账单也是950元。人脑会自动判断"以账单为准"，但AI往往拿不准。

ATM-Bench专门设置了这种"证据打架"的场景。结果？AI要么两个都采信得出错误答案，要么随机选一个赌运气。

### 死穴三：跨模态关联——"餐厅名字在邮件里，照片里没有GPS"

这是最难的一关。人类回忆一件事时，大脑会自动把不同来源的碎片串起来：邮件里的餐厅名字 + 照片里的菜品 + 当时的GPS位置 = 一次完整的用餐记忆。

但AI目前大多只能单线程处理。让它读邮件就只会读邮件，看照片就只会看照片。把两者关联起来？那是另一个维度的问题了。

## 三、大厂们的"记法"，各有各的毛病

面对"健忘"这个共同难题，各家AI产品走了不同的路线，但都有明显的短板。

**Claude**走的是"主动记忆"路线。它的Memory功能会自动检测对话中值得记住的信息——你的偏好、工作风格、重要事实——然后保存下来，下次对话时调取。听起来不错，但实际体验是：覆盖面有限，很多重要信息它根本意识不到该记。就像有个勤快的实习生，只记老板明说的话，老板的潜台词和上下文全忽略了。

**ChatGPT**走的是"混合记忆"路线。一部分靠用户主动触发"记住这件事"，一部分靠AI自己猜测"这个该记住吗"。问题在于，上下文窗口有限，长对话到后面还是会"失忆"。就像你有一本笔记本，前面记满了，后面的内容就把前面的挤掉了。

**Gemini**宣称自己有百万token的上下文窗口，看起来能装下整本记忆。但实际用户反馈是："对话超过10轮，它完全忘了我复制粘贴的所有代码。"窗口大不等于记得牢，注意力机制在长文本中会"涣散"，这种现象叫"context rot"（上下文腐烂）。

**OpenClaw**（一个开源的AI助手开发框架）走了另一条路：用文件存储记忆。对话内容自动存成Markdown文件，配合混合搜索来调取。好处是透明、可控，用户自己能打开文件看AI记住了什么。但缺点是依赖本地存储，没有云端同步，换台设备记忆就没了。今年4月12日，OpenClaw团队推出了Active Memory插件，强制AI每次回复前检索全部记忆——这是把"被动回忆"变成了"主动翻旧账"的硬流程。

**国内这边**，阿里千问、百度文心、字节豆包等主流产品，长期记忆功能大多还在初级阶段。普遍做法是保存对话历史，但真正的"跨会话个性化记忆"（比如记住你是程序员、不喜欢辣、家在朝阳区）还很不成熟。

## 四、有人已经开始"治"AI的健忘症了

别看巨头们还在摸索，创业圈已经嗅到了机会。

**Cognee**是一家柏林的AI基础设施公司，今年2月拿到了**750万欧元（约5800万人民币）种子轮融资**，专门做"企业级AI助手记忆层"。它的思路是：给不同的AI助手建一个统一的记忆数据库，它们可以共享记忆，就像公司里的员工共享通讯录一样。

**Reload**是一家美国公司，今年2月融资**227.5万美元**，推出了第一个"AI员工"Epic。它的卖点是给AI助手一个共享记忆，让它们像团队协作一样互通信息，而不是各自为政。

开源社区也没闲着。**Mem0**是一个开源的记忆层项目，被很多开发者用来给AI助手添加长期记忆能力。它允许开发者自定义记忆的存储和检索方式，灵活性很高。**A-Mem**和**HippoRAG**是学术界的前沿方案，分别在记忆的"分层组织"和"检索增强"上做文章。

剑桥大学团队自己也没光出题不答题。他们提出了一个叫**Schema-Guided Memory（SGM，模式引导记忆）**的新方法。简单来说，就是不给AI写一大段文字描述记忆，而是把每个记忆拆成标准化字段：时间、地点、人物、事件类型、标签。就像把一本没目录的书改成了有索引的数据库，检索效率大幅提升。实验证明，SGM比传统的"描述性记忆"方法效果好得多。

有意思的是，研究团队还对比了两种记忆组织方式：一种是把所有记忆"堆在一起"（堆叠式），一种是把相关记忆自动关联成网络（关联式）。结果出乎意料——**简单的堆叠式在某些场景下反而比复杂的关联式表现更好，而且构建速度快得多**。这个发现提醒我们：解决AI失忆，不一定需要更复杂的算法，有时候更简单的方法反而更有效。

## 五、这件事到底跟你有什么关系？

ATM-Bench的发布之所以引发关注，不是因为它的测试方法有多新颖，而是因为它戳中了一个行业共识：**没有长期记忆，AI助手永远只是高级聊天机器人。**

2026年被很多人称为"AI助手元年"。各种智能助手框架、AI应用、自动化平台层出不穷。但一个核心问题始终没解决：如果AI助手记不住你，它怎么"个性化"？如果它每次对话都像第一次见面，怎么建立信任？如果它处理不了你的历史数据，怎么帮你管理生活？

ATM-Bench用数据告诉我们：**当前AI的"个性化"，很大程度上是幻觉**。它可能只是根据你当前输入的几个词做了点表面功夫，而不是真正理解了你的过去、偏好和上下文。

稀土掘金的一篇行业周报把这个问题总结得很到位："工具链再完善、模型再强大，也弥补不了记忆架构上的根本缺陷。当AI连'去年给妈妈买的相机'都记不住时，真正的'个性化AI助手'仍是远景。"

但换个角度看，这也意味着**记忆层是一个巨大的创业和投资机会**。就像当年云计算解决了"存储"问题、数据库解决了"查询"问题一样，AI记忆层可能会诞生下一个独角兽。

## 六、三条你可以马上做的事

1. **测试一下你的AI助手，看它真的记得你吗**
   跟它聊几个来回，然后新开一个对话窗口，问它"你还记得我们刚才聊的XXX吗"或者"我之前告诉过你我喜欢XXX，你还记得吗"。如果它一脸茫然，说明它的记忆功能基本上就是个摆设。把测试结果截图发给我，我们可以一起分析。

2. **如果你在用OpenClaw等开源框架，试试Active Memory**
   OpenClaw今年4月推出的Active Memory插件，强制AI每次回复前检索全部记忆。这是一个简单但有效的"笨办法"——既然AI懒得回忆，那就给它定个规矩必须翻旧账。虽然会影响一点响应速度，但记忆准确性会明显提升。其他开源框架也有类似的记忆插件，值得一试。

3. **关注AI记忆方向的创业公司和开源项目**
   Cognee、Mem0、A-Mem这些项目都在探索不同的记忆方案。如果你是开发者或产品经理，可以提前了解它们的技术路线，看哪种更适合你的应用场景。如果你只是普通用户，关注这些项目的进展，可以让你在选择AI产品时多一个判断维度——"它的记忆功能到底靠不靠谱"。

## 写在最后

剑桥大学这个研究团队，用4年时间建了一个"数字人生"，然后用1038道考题测出了AI行业的集体失忆症。

最好的学生考了不到20分。这不是羞辱，而是提醒：我们在欢呼AI能写诗、能写代码、能画图的时候，别忘了它连"去年发生的事"都记不清楚。

记忆是智能的基石。人类之所以聪明，很大程度上是因为我们能记住过去、从中学习、然后做出更好的决策。AI如果连这一步都跨不过去，"通用人工智能"就还远着呢。

ATM-Bench像一面镜子，照出了行业的短板。但也正是因为有了这面镜子，我们才知道该往哪走。
