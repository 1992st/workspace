"你是谁"
  • 1 接收用户消息
    Gateway 接收 "你是谁"，开始 Agent Loop
  • 2 加载历史记录
    从 session.jsonl 读取空历史（新会话）
  • 3 检查 Bootstrap 状态
    hasCompletedBootstrapTurn() 检查
  • 4 加载工作区文件
    读取 AGENTS.md / SOUL.md / USER.md 等
  • 5 构建 System Prompt
    调用 buildAgentSystemPrompt()

    区分稳定部分和动态部分
  • 7 注入用户消息
    将 "你是谁" 加入 messages 列表
  • 8 发送给 LLM
    完整的 System Prompt + User Message
