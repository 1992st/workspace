🔧 OpenClaw Agent 启动流程

源码级 Prompt 拼接过程 · 基于 system-prompt.ts 与 agent-loop.md

  • 1 确定 Prompt Mode
    默认 full 模式，加载全部系统提示
  • 2 构建基础身份行
    注入 "You are a personal assistant..."
  • 3 加载 Tooling 规则
    工具调用规范、Cron 规则、执行偏向
  • 4 注入安全护栏
    Safety 规则、自我保护禁止
  • 5 加载 CLI 快速参考
    OpenClaw 子命令规范
  • 6 注入 Skills 规则
    扫描可用技能、加载 SKILL.md
  • 7 加载记忆检索规则
    Memory Recall 机制
  • 8 注入工作区上下文
    AGENTS.md / SOUL.md / TOOLS.md 等
  • 9 添加运行时信息
    Runtime 环境快照
  • 10 发送给 LLM
    最终 System Prompt 完成
