# DeepSeek融资真相：撕开表面文章，谁在给谁打工？

## 核心发现

**DeepSeek融资不是"主动战略布局"，而是"被动求生"**。幻方量化一年赚50亿，但DeepSeek一年可能烧掉30-50亿。梁文锋的红线被打破，不是因为"现实主义"，是因为**钱真的快烧完了**。

但这件事的戏剧性在于：表面上是DeepSeek在"卖身"，实际上**阿里腾讯才是被绑架的一方**——他们不得不投，因为谁错过DeepSeek，谁就可能错过国产AI的定价权。

## 一、DeepSeek V4：技术突破还是生存宣言？

### 1.1 模型本身

4月24日，DeepSeek V4正式发布，包含两个版本：
- **V4-Pro**：高性能版，百万字超长上下文
- **V4-Flash**：轻量版，推理成本更低

关键能力：
- 在Agent能力、世界知识、推理性能上，国内和开源领域领先
- 明确支持华为昇腾950芯片，从CUDA生态切换至CANN框架
- API定价仅为GPT-5.4的二十分之一

### 1.2 比模型更重要的：芯片选择

DeepSeek V4最引爆市场的不是参数，而是这句话：**"首次基于华为昇腾950训练"**。

这意味着什么？
- **技术独立**：不再依赖英伟达GPU和CUDA生态
- **成本重构**：昇腾950的性价比可能重塑训练成本结构
- **供应链安全**：在中美科技博弈背景下，"全国产"本身就是估值溢价

华为同步宣布：昇腾超节点全系列产品支持DeepSeek V4系列模型。昇腾950通过融合kernel和多流并行技术，大幅降低Attention计算和访存开销，实现高吞吐、低时延推理部署。

## 二、幻方量化：DeepSeek的"金主爸爸"还能撑多久？

### 2.1 幻方的真实财力

| 指标 | 数据 | 来源 |
|------|------|------|
| 管理规模 | 超700亿人民币 | 私募排排网 |
| 2025年收益均值 | 56.55% | 私募排排网 |
| 估算年收入 | 50亿人民币+ | 按1%管理费+20%绩效费 |
| 近三年收益均值 | 约35% | 新浪财经 |

**50亿年收入是什么概念？**
- 够训练1.5个GPT-4级别的模型（单次训练成本约30-40亿人民币）
- 够发500个顶级AI研究员的年薪（年薪千万级）
- 但**不够**维持DeepSeek一年的全面开支

### 2.2 DeepSeek的真实烧钱速度

**训练成本：**
- V4训练使用数万张昇腾950卡
- 单卡成本：5-7万元（按375-525亿营收/75万片计算）
- 假设使用1万张卡训练3个月：
  - 硬件折旧：1万卡 × 6万元 ÷ 4年 × 0.25年 = **3.75亿**
  - 电费：1万卡 × 400W × 24h × 90天 × 0.8元/kWh = **约7亿**
  - 人力：500人团队 × 年薪100万 = **5亿**
  - **单次训练总成本：约15-20亿**

**推理成本（更可怕）：**
- 中国日均Token消耗从2024年初1000亿飙升至2026年2月的180万亿
- 2年增长1800倍
- DeepSeek作为开源模型被广泛使用，推理成本主要由云厂商承担
- 但DeepSeek官方API的运营成本：
  - 假设日调用量10万亿Token
  - 每百万Token成本约0.5元
  - **日成本：500万元，年成本：18亿+**

### 2.3 幻方的现金流能撑多久？

**乐观估算：**
- 幻方年收入50亿，利润约30亿
- DeepSeek年烧钱：训练20亿 + 推理18亿 + 人力10亿 = **48亿**
- **幻方利润几乎全填DeepSeek，还不够**

**现实情况：**
- 幻方量化2026年收益可能不及2025年（市场波动）
- 量化行业监管趋严，费率可能下调
- **DeepSeek的现金流缺口：每年20-30亿**

**结论：梁文锋不是"现实主义转身"，是"没得选了"**

## 三、昇腾950的真实成本和产能

### 3.1 芯片价格背后的水分

**华为官方数据：**
- 2026年出货量目标：75万片
- 预计营收：375-525亿人民币
- **单颗均价：5-7万元**

**但这里面有水分：**
- 375-525亿是"芯片+服务器+解决方案"打包价
- 纯芯片ASP（平均售价）可能只有3-4万元
- 对标英伟达H100（约20万元），昇腾950性价比确实高
- 但**性能差距仍然存在**，需要更多芯片弥补

### 3.2 产能瓶颈

**中芯国际的困境：**
- 昇腾950采用7nm工艺（华为自研，中芯代工）
- 中芯国际7nm良率约60-70%（台积电90%+）
- 美国制裁导致EUV光刻机无法进口，先进制程扩产受限
- **75万片目标很激进，实际可能只能交付50-60万片**

**对DeepSeek的影响：**
- 如果昇腾产能跟不上，DeepSeek的训练计划会延迟
- 需要提前锁定芯片供应，这需要大量预付款
- **融资的紧迫性之一：提前锁定昇腾产能**

## 五、200亿估值的经济账：谁赚了谁亏了？

### 5.1 从成本角度算

**DeepSeek的"重置成本"：**
- 人才：500人 × 人均成本200万/年 × 3年 = **30亿**
- 算力：3年训练+推理 = **100亿+**
- 品牌/生态：开源社区影响力 = **难以估量**
- **重置成本至少150-200亿人民币**

**200亿美元（1400亿人民币）vs 重置成本：**
- 看起来溢价很多
- 但考虑到时间成本（3年迭代）和人才稀缺性
- **200亿其实不贵**

### 5.2 从收入角度算

**DeepSeek的收入现状：**
- API收入：定价仅为GPT-5.4的二十分之一
- 假设日调用10万亿Token，年收入约1-2亿人民币
- 开源模型收入：几乎为零
- **年收入可能不到5亿人民币**

**200亿美元估值 vs 年收入：**
- PS倍数：280倍+
- 这看起来极其荒谬
- **但AI公司的估值从不看当前收入，看的是"生态位"**

### 5.3 从博弈角度算

**如果阿里腾讯不投DeepSeek：**
- 阿里：阿里云缺乏顶级模型，竞争不过腾讯云+DeepSeek组合
- 腾讯：微信AI化落后，字节豆包可能抢占先机
- **两家都有"不得不投"的压力**

**梁文锋的议价能力：**
- 表面：主动压低估值，换生态支持
- 实际：急需资金续命，但不愿被一家控制
- 引入两家互相制衡，保持独立性
- **这是"弱者的博弈技巧"，不是"强者的战略布局"**

## 六、为什么只选阿里腾讯？为什么只给9%？

### 6.1 份额：给得极少

| 参数 | 数据 |
|------|------|
| 融资总额 | 18亿美元（阿里+腾讯合计） |
| 估值 | 200亿美元+（约1400亿人民币） |
| 出让股权 | **约9%** |
| 每家可能分到 | 各投9亿美元 ≈ **各4.5%** |

**对比之下：**
- 4月17日最初传的是3亿美元/100亿估值 = **仅3%**
- 后来估值抬到200亿，融资额也抬到18亿，比例反而变成了9%
- 但即便如此，梁文锋+幻方仍**绝对控股**（90%+）

### 6.2 为什么只选阿里腾讯，不接别人的钱？

**原因1：梁文锋的根本底线——不能让资本干扰技术决策**

> "他曾先后拒绝腾讯、阿里等巨头的投资意向，理由朴素而清晰：资本会干扰技术决策。"

这是36氪的爆料。梁文锋之前一直不融资，不是因为不缺钱，是因为怕失去控制权。现在被迫融资，第一优先级就是：**找"能用但不管事"的钱**。

**原因2：阿里腾讯是"战略投资人"，不是"财务投资人"**

| 对比 | PE/VC（红杉、高瓴等） | 阿里腾讯 |
|------|----------------------|---------|
| 目的 | 财务回报、推动上市/并购 | 生态绑定、云服务销售 |
| 干预度 | 高（要董事会席位、要业绩承诺） | **低**（要API调用、要云订单） |
| 退出压力 | 强（5-7年必须退出） | 弱（战略持有，不急着卖） |
| 附加价值 | 钱+人脉 | **算力+流量+云订单** |

**阿里腾讯投DeepSeek，本质上是在"买云客户"，不是在"买股权增值"。** 他们不太会逼梁文锋做商业决策。

**原因3：两家互相制衡，比一家安全**

如果只接阿里：
- 阿里云可能成为DeepSeek的"独家云"
- 通义千问可能成为"优先模型"
- 阿里会逐渐把DeepSeek变成附庸

如果同时接阿里+腾讯：
- 两家都有钱，互相盯着
- 谁也不敢提过分要求
- **梁文锋可以在中间玩平衡**

这是弱者的博弈技巧。

**原因4：其他投资人"不够格"**

> "DeepSeek公司高层明确对商业化不感兴趣，只想做技术研究。而投资机构需要通过公司进行商业化变现..."

传统VC的投资逻辑（商业化、上市、退出）和DeepSeek的基因完全冲突。

### 6.3 为什么份额只给9%，不多融点？

**逻辑1：够用就行，不想多卖**

按之前的分析：
- DeepSeek年烧钱：48亿
- 这次融18亿美元 ≈ **130亿人民币**
- 够烧 **2.5-3年**

梁文锋的想法可能是：**融够2-3年的钱，但不卖太多股权。** 等模型迭代、生态做大，下一轮估值可能更高，到时再少卖一点股权就能融到同样的钱。

**逻辑2：保持控制权是第一优先级**

9%的股权意味着：
- 阿里腾讯**没有一票否决权**（通常10%以上才有）
- **没有董事会席位**（可能就一个观察员）
- 纯粹是"财务+战略"投资，不参与管理

**逻辑3：为后续融资留空间**

如果这轮卖了20%，下轮再卖20%，几轮之后梁文锋就失控了。但只卖9%，后续还有**很大的融资空间**。

## 七、中美脱钩的真实影响：供应链风险被低估

### 7.1 昇腾芯片的"卡脖子"风险

**华为和中芯国际的脆弱性：**
- 7nm工艺依赖DUV光刻机（可进口但效率低）
- 先进封装材料可能被制裁
- 如果美国升级制裁，昇腾产能可能骤降

**对DeepSeek的影响：**
- 如果昇腾供应中断，DeepSeek的训练计划泡汤
- 需要囤积芯片，这需要大量资金
- **融资的紧迫性之二：应对地缘政治风险**

### 7.2 人才流失风险

**数据：**
- 2025-2026年，中国AI人才赴美/赴新加坡比例上升
- OpenAI、Anthropic在中国高薪挖角
- DeepSeek核心团队被挖角的风险

**融资的防御性功能：**
- 拿钱发期权，绑定核心人才
- 展示"有大厂支持"，增强团队信心
- **融资的紧迫性之三：人才保卫战**
