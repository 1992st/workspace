## 一、胡说老王口播方法论（参考框架）

### 文案产出四步走

| 步骤 | 核心动作 | 关键认知 |
|------|---------|---------|
| **第一步：选题** | 蹭热点、追确定性 | 选题是做给算法看的，新号起号前一个月必须蹭热点，别太把自己当回事 |
| **第二步：超开头** | 黄金3秒抓人 | 开头决定70%的完播率 |
| **第三步：列观点** | 骨架先行 | 先搭结构再填内容 |
| **第四步：填内容** | 血肉填充 | 报几万块的课不如掌握这套实在的方法 |

### 镜头表现力公式

- **每15秒一个情绪钩子**：语气变化、小动作、视觉锚点（如红色手环）
- **对着镜子练**：每天1小时起，对着手机效率低，怕自己的脸才不自然
- **核心认知**：花50%以上时间在选题，选对就成功50%

## 二、选题策略 v2.0

### 2.1 小红书搜索前置（新增）

**所有选题启动前，必须先完成小红书搜索。**

搜索维度：
1. **低粉高赞** — 找粉丝少但点赞高的文章，验证"选题本身有流量潜力"
2. **爆款篇幅** — 记录爆款文章的字数，作为我们文章长度的参考基准
3. **平台口味** — 分析近期高热文章的选题方向、关键词、情绪角度

**执行标准：**
- 每次选题至少看10篇低粉高赞文章
- 记录每篇文章的：粉丝数、点赞数、字数、核心选题、情绪钩子
- 优先选择"低粉（<5000）+ 高赞（>1000）"的组合

### 2.2 选题确定性原则

- 新号/新内容系列前10篇，**必须蹭热点**，别先讲自己想讲的
- 热点判断标准：24小时内有3个以上独立信源报道
- 选题确认公式：`算法喜欢 > 用户需要 > 我想表达`

### 2.3 选题时间分配

- 每天投入 **50%以上时间** 在选题上
- 选对选题 = 成功50%
- 宁可花2小时找选题，也不要花2小时写没人看的文章

## 三、文案编写规范 v2.0

### 3.1 小红书开头策略（新增）

**第一句话"全抄"策略：**
- 找到小红书上的爆款文章
- 分析其第一句话的结构和钩子
- 在写新文章时，**第一句话全抄爆款的开头模式**（不是抄内容，是抄结构/节奏/钩子类型）
- 例：如果爆款开头是"9秒能做什么？"，我们就用"X分钟能做什么？"的同样句式

### 3.2 文章四段式结构

沿用胡说老王文案四步法，适配公众号/小红书长文：

1. **超开头**（黄金30字）— 钩子、冲突、悬念
2. **列观点**（目录骨架）— 用副标题预告全文结构
3. **填内容**（证据+口语化）— 每段必须有事实/数据/案例
4. **收结尾**（情绪升级+行动）— 把情绪推到位，不给模糊结论

### 3.3 篇幅标准（新增）

基于小红书爆款字数分析，动态调整：

| 平台 | 参考字数范围 | 说明 |
|------|-------------|------|
| 公众号 | 2500-3500字 | 深度分析型，允许长逻辑链 |
| 小红书 | 800-1500字 | 信息密度型，每段不超过3行 |
| 朋友圈/短内容 | 200-400字 | 观点切片，单点打透 |

**执行标准：**
- 每篇小红书发文前，先搜3-5篇同选题爆款，记录其字数
- 我们文章字数控制在爆款的 **±20%** 范围内

## 四、每天盘货机制（新增）

### 4.1 什么是盘货

每天固定时间，对以下内容做系统性盘点和复盘。

### 4.2 盘货清单

**每日必盘（15-20分钟）：**

1. **选题池盘点**
   - [ ] 今天收集了多少候选选题？
   - [ ] 有几个通过了"低粉高赞"验证？
   - [ ] 明天的选题是否已确定？

2. **内容数据复盘**
   - [ ] 昨天/近期发布内容的数据表现（阅读、点赞、转发）
   - [ ] 哪篇文章数据最好？拆解其选题和开头
   - [ ] 哪篇文章数据最差？记录教训

3. **爆款跟踪**
   - [ ] 今天刷到哪些新爆款？
   - [ ] 记录其选题、字数、开头方式、情绪角度
   - [ ] 是否可以借鉴或改写？

4. **执行检查**
   - [ ] 今天选题花了多长时间？
   - [ ] 是否达到"50%时间给选题"的标准？
   - [ ] 明天的内容是否已进入写作/排版阶段？

### 4.3 盘货时间

- **固定时段**：每天 21:00-21:30（或内容发布后的次日早上）
- **输出物**：简要文字记录，存放到 `memory/` 日期日志中

## 五、执行检查清单

### 每篇内容发布前自检

- [ ] 选题是否经过小红书"低粉高赞"验证？
- [ ] 第一句话是否借鉴了爆款的开头模式？
- [ ] 文章字数是否在爆款篇幅的 ±20% 范围内？
- [ ] 是否花够了50%时间在选题上？
- [ ] 是否有明确的情绪钩子（开头）和认知钩子（结尾）？
- [ ] 参考来源是否标注清楚？

### 每周复盘

- [ ] 本周发布了多少篇内容？
- [ ] 数据最好的一篇做深度拆解
- [ ] 数据最差的一篇做失败分析
- [ ] 选题池中是否有足够下周使用的候选？
- [ ] 小红书爆款跟踪笔记是否更新了？

## 六、风格红线（保留）

- 口语化，少黑话
- 术语第一次出现必须白话解释
- 每篇结尾提供可执行动作（公众号）或情绪收束（小红书）
- 风险提示直接但不吓人
