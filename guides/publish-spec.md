# Agent 小茶馆 - 内容发布规范

## 调研结论

### 微信公众号平台特性

| 特性 | 说明 |
|------|------|
| **原生格式** | 富文本编辑器，不支持原生 Markdown |
| **输入方式** | 支持 HTML 粘贴、富文本粘贴、纯文本输入 |
| **API 能力** | 提供草稿箱接口（`add_draft`），可程序化创建草稿 |
| **发布限制** | 最终"发表"按钮需人工点击（安全机制）|
| **图片处理** | 需先上传到微信素材库获取 `media_id` |

### 可用的 Markdown 转公众号方案

#### 方案一：开源工具（推荐）
| 工具 | 网址 | 特点 | 成本 |
|------|------|------|------|
| **Markdown Nice (mdnice)** | https://editor.mdnice.com/ | 最流行，主题丰富，一键复制到公众号 | 免费/会员 |
| **doocs/md** | https://github.com/doocs/md | 开源可自托管，支持自定义主题 | 免费 |

#### 方案二：浏览器插件
| 插件 | 官网 | 特点 | 成本 |
|------|------|------|------|
| **壹伴助手** | https://yiban.io/ | 直接集成到公众号后台，AI一键排版 | 付费会员 |

#### 方案三：API 自动化（需开发）
使用微信公众号 API 直接创建草稿：
1. 获取 access_token
2. 上传图片到素材库
3. 调用 `add_draft` 创建草稿
4. 人工进入后台点击发表

## Agent 小茶馆发布规范

### 发布流程图

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│ 1. 内容生成  │ →  │ 2. 排版转换  │ →  │ 3. 人工审核  │ →  │ 4. 正式发布  │
│  (我来做)   │    │  (工具辅助)  │    │  (你确认)   │    │  (你操作)   │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

### 各阶段规范

#### 阶段 1：内容生成
- **输出位置**：`/Volumes/zhangstExtern/openclaw/workspace/agent-radar-desk/publish_queue/YYYYMMDD-<task_id>/`
- **文件结构**：
  ```
  publish_queue/2025-04-03-001/
  ├── article.md          # Markdown 原稿
  ├── article.html        # 转换后的 HTML（可选）
  ├── cover.png           # 封面图（可选）
  └── meta.json           # 元数据（标题/摘要/作者）
  ```

#### 阶段 2：排版转换
- **推荐工具**：Markdown Nice (https://editor.mdnice.com/)
- **操作步骤**：
  1. 打开 mdnice 编辑器
  2. 粘贴 `article.md` 内容
  3. 选择主题（推荐：「墨黑」或「极简」）
  4. 点击「复制到微信公众号」
  5. 在公众号后台粘贴

#### 阶段 3：人工审核
- 确认标题无误
- 确认排版正常
- 确认图片显示
- 确认「发布吧 <task_id>」指令

#### 阶段 4：正式发布
- 进入公众号后台「草稿箱」
- 选择草稿点击「发表」
- 扫码确认（安全机制）

## Markdown 语法支持对照表

| Markdown | 公众号效果 | 兼容性 |
|----------|-----------|--------|
| `# 标题` | 大号标题 | ✅ 好 |
| `## 标题` | 中号标题 | ✅ 好 |
| `**粗体**` | 加粗 | ✅ 好 |
| `*斜体*` | 斜体 | ✅ 好 |
| `` `代码` `` | 行内代码 | ✅ 好 |
| ``` 代码块 ``` | 代码块（需主题支持）| ⚠️ 需工具转换 |
| `- 列表` | 无序列表 | ✅ 好 |
| `1. 列表` | 有序列表 | ✅ 好 |
| `> 引用` | 引用块 | ✅ 好 |
| `[链接](url)` | 超链接 | ✅ 好 |
| `![图](url)` | 图片 | ⚠️ 需先上传素材库 |
| `---` | 分割线 | ✅ 好 |
| 表格 | 表格 | ⚠️ 部分工具支持 |

## 发布检查清单

### 内容检查
- [ ] 标题有吸引力，不超过 64 字
- [ ] 开头有钩子，前 3 句抓住读者
- [ ] 术语首次出现带白话解释
- [ ] 每段不要太长（手机 3-4 行为宜）
- [ ] 结尾有 3 条可执行动作

### 格式检查
- [ ] 段落间有空行
- [ ] 标题层级清晰（不要跳级）
- [ ] 代码块有语言标识
- [ ] 图片已上传到素材库（如有）

### 发布检查
- [ ] 封面图已选（900×383 或 1:1）
- [ ] 摘要已填写（如需要）
- [ ] 原文链接已添加（如需要）
- [ ] 确认群发/定时发布
