# 选题四层深研规范（45 分钟）

## 目标
解决“选题前资料搜索粗糙”的问题，保证每次选题都可追溯、可比较、可落地。

## 流程
1. **L1 热点池（10 分钟）**
   - 收集不少于 20 条候选
   - 每条必须包含：来源、发布时间、事件一句话
2. **L2 证据评分（12 分钟）**
   - 评分维度：新颖性、可验证性、传播性、商业相关
   - 统一 1-5 分，附一句理由
3. **L3 深度复核（13 分钟）**
   - 查反证：是否存在相反观点
   - 查边界：结论在什么条件下失效
   - 查风险：误导风险、时效风险、数据风险
4. **L4 成稿决策（10 分钟）**
   - 输出 Top 3 选题卡
   - 每张卡必须包含：受众、核心冲突、推荐理由、3 条可执行动作

## 输出模板
```yaml
task_id: ""
topic_id: ""
title: ""
score_breakdown:
  novelty: 0
  verifiability: 0
  spreadability: 0
  business_relevance: 0
evidence_links: []
why_now: ""
risks: []
next_actions: []
```

## 验收标准
- 候选条目数 >= 20
- Top 3 每个都有评分与证据链接
- 每个选题卡都有 3 条可执行动作
