# 🚨 这家 AI 公司 3 年涨 10 倍，最火产品却只赚 18%——华尔街终于看懂了

> 💡 **核心发现**：Anthropic 年收入破 140 亿美元，Claude Code 仅占 18%，却引发了 2850 亿美元抛售潮——为什么？

2026年2月，华尔街发生了一件奇怪的事。

一家成立不到 3 年的 AI 公司 **Anthropic** 宣布：<span style="color:#ec4899;font-weight:bold;">年收入突破 140 亿美元</span>。

但市场关注的不是它多赚钱，而是它<span style="color:#ec4899;font-weight:bold;">最火的产品 Claude Code 只贡献了 18% 收入</span>。

更奇怪的是，这个消息一出来，软件股集体暴跌——**2850 亿美元市值蒸发**。

为什么"最好用"的产品不赚钱？为什么华尔街反而慌了？

今天一次讲清楚。

## 三、为什么是 Coding 先跑通？

Claude Code 发布不到一年，为什么能占 4% 的 GitHub 提交？

| 场景 | AI 适配度 | 为什么 |
|------|-----------|--------|
| **Coding** | ⭐⭐⭐⭐⭐ | 结构化、有明确对错、工具链成熟 |
| **法律服务** | ⭐⭐⭐⭐ | 文档处理、高毛利、强合规 |
| **金融分析** | ⭐⭐⭐⭐ | 数据驱动、标准化流程 |
| **医疗** | ⭐⭐⭐ | 专业壁垒高、数据敏感 |

**Coding 是 AI Agent 的"低垂果实"**：
- GitHub 上 4% 的公开代码提交来自 Claude Code（1 个月翻倍）
- 企业开发团队每周节省 **8-10 小时**
- 80% 的任务不需要人工干预

更重要的是：<span style="color:#ec4899;font-weight:bold;">软件工程是科技行业的基础设施</span>。这里被攻克，其他行业的信心就来了。

## 五、Claude for Financial Services：不只是"插件"

很多人以为 Anthropic 只是发布了几个 Plugin。实际上，这是一套**完整的解决方案**：

### 1. Claude for Excel（测试版）
- 在 Excel 侧边栏直接与 Claude 对话
- 读取、分析、修改、创建 Excel 文件
- 保留公式依赖，追踪修改记录

### 2. 数据连接器（Connectors）

| 数据源 | 提供什么 |
|--------|----------|
| **LSEG** | 实时市场数据、股价、外汇 |
| **Moody's** | 6亿+公司信用评级、财务数据 |
| **Aiera** | 财报电话会议实时转录 |
| **S&P Capital IQ** | 投资银行数据 |

### 3. Agent Skills（代理技能）
- ✅ 可比公司分析（自动刷新估值倍数）
- ✅ DCF 估值模型（含敏感性分析）
- ✅ 尽职调查数据包（从文档提取关键信息）
- ✅ 覆盖报告生成

**关键点**：这些不是"工具"，是<span style="color:#ec4899;font-weight:bold;">能独立完成任务的 Agent</span>。
