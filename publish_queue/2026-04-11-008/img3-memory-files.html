文件布局与数据结构对比
Claude Code纯 Markdown
~/.claude/projects/<project>/memory/
~/.claude/projects/<project>/memory/ ├── MEMORY.md ← 索引（200行轻量目录） ├── logs/ │ └── YYYY/MM/... ← 日常日志（assistant模式） ├── frontend-refactor.md ← topic 记忆正文 ├── api-design.md ← topic 记忆正文 └── user-preferences.md ← topic 记忆正文
特点：没有额外的机器状态文件。所有整理决策由 LLM 子代理完成，输出全是人类可读的 markdown。
OpenClawMarkdown + JSON
<workspace>/
<workspace>/ ├── MEMORY.md ← 长期记忆（直接注入prompt） ├── memory/2026-04-11.md ← 日常笔记 ├── DREAMS.md ← Dream Diary（给人读的） └── memory/.dreams/ ├── short-term-recall.json ← 召回记录数据库 ├── phase-signals.json ← light/REM 强化信号 ├── daily-ingestion.json ← 每日摄取状态 ├── session-ingestion.json ← 会话摄取状态 ├── session-corpus/ │ └── 2026-04-11.txt ← 提取的会话语料 └── short-term-promotion.lock ← 文件锁
特点：用 JSON store 记录所有量化数据。Dreaming 的决策由算法驱动，DREAMS.md 只供人类 review。
