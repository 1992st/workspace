## 案例 001：国泰海通 601211 — 基于4天数据得出完全相反的结论

**日期**: 2026-05-08
**错误等级**: 🔴 致命（如果实盘操作将直接亏钱）

### 事件经过

| 轮次 | 数据范围 | 结论 | 置信度 | 实际 |
|------|---------|------|--------|------|
| 第一轮 | 只看5月4天 | 建议减仓 | 隐含80%+ | ❌ 完全错误 |
| 第二轮 | 补充4月+基本面 | 不应减仓 | 70% | ✅ 接近真相 |

**错误方向**：把"筑底企稳"误判为"即将破位"

### 错误链条

```
输入：5/5-5/8 四天数据（197万→121万→103万→126万）

① 看到4/27放量201万跌到16.10
  → 叙事："放量破位"
  → 事实：之后4天都在16.12收回来 → 是筑底不是破位

② 看到5/6放量197万冲到16.45又跌回来
  → 叙事："放量失败，多头溃败"
  → 事实：即使失败也未跌破16.00 → 这叫"试盘"

③ 看到今天最低16.01
  → 叙事："第3次测试，事不过三"
  → 事实：是第5次，前4次都守住了

三个叙事，全是错的。三个事实，全是反的。
```

### 五大根因

#### 根因1：近因效应 (Recency Bias) — 最致命

- 只看5月4天数据就下结论
- 没看4月数据（4/27放量后企稳4天）
- 如果看了4月：叙事从"放量破位"→"放量探底后企稳"，结论反转

#### 根因2：单变量决策

- 只分析了量+价两个维度
- 漏掉的关键证据：
  - PB = 0.85倍（破净，极低估值）
  - Q1扣非+73.4%（高增长）
  - 16.00测试了5次都守住（铁底）
  - 2025年同期缩量到18万（当时没破位，现在也不会）

#### 根因3：叙事代替证据

- "放量失败" — 听起来合理，但是叙事不是证据
- "多头溃败" — 听起来合理，但是叙事不是证据
- "事不过三" — 听起来合理，但是叙事不是证据
- 真正的证据：5次测试守住、PB破净、业绩高增

#### 根因4：单向论证（无对抗性验证）

- 第一次分析：找支持减仓的论据 → 减仓 → 结束
- **跳过了强制反证步骤**

#### 根因5：跨品种套用框架

- 中航成飞（军工高波动）：放量=资金看到催化=暴涨
- 国泰海通（低估券商）：放量≠启动，可能只是试盘
- 不同品种的量价语言完全不同

### 修复规则（已写入分析流程）

| 问题 | 从"自觉"到"机械" |
|------|-----------------|
| 数据不全 | **分析前必须跑 `python3 scripts/analysis_gate.py CODE`**，5项数据检查不通过 → 拒绝分析 |
| 单向论证 | 分析流程步骤3：强制写反对意见（长度≥正论）|
| 叙事陷阱 | 每条结论必须引用具体数字，禁止模糊叙事 |
| 置信度校准 | 门控分数自动映射置信度上限（≤60分→≤30%，≥85分→≤80%）|
| 框架套用 | 每个股票独立分析，禁止"和XX股一样"式推理 |

### 根本改进

之前的修复是"提醒自己要做某件事"——LLM agent 会跳过。
现在的修复是"不过门不让过"——机械约束。

```
分析请求 → analysis_gate.py → ready=false → ❌ BLOCKED（返回缺口清单）
                            → ready=true  → ✅ 开始分析
```

门控脚本检查6个维度：
- K线 ≥ 40根（目标60天）
- 实时行情（含PE/PB/市值）
- 大盘指数（上证/深证/创业板）
- 行业板块
- 估值数据（PE/PB）

### 反思

> 如果只用50%的数据下80%置信度的结论，不是分析师，是算命的。
>
> 这次翻车暴露的不是技术问题，是**方法论的底层缺陷**——用太少的数据、太窄的维度、太快的速度做太确定的判断。
>
> 幸运的是这次在复盘中被发现。如果不修复这个缺陷，未来会以同样的方式错更多次。
