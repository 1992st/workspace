# 个股特征分析表 — 设计说明（模板）

> 目标：每只股票一份独立的、结构化的特征分析表格文件，每次整理全量重写，不搞分散描述。
> 落点：`data/watchlist/active/{code}/{code}_特征表.md`（人读 + 机器可解析的统一结构）

---

## 设计原则

1. **一份一票，全量重写**：每次复盘/整理，整份表格重写，不追加、不遗留旧数据。
2. **不用 sqlite**：直接用 Markdown 表格承载，人读清晰，且字段规整可被脚本解析。
3. **字段固定**：所有股票用同一套字段，方便横览对比。
4. **随复盘更新**：盘后复盘时，逐只全量更新这张表，作为该股"当前状态的唯一快照"。

---

## 表格模板（每只股票一份）

```markdown
# {名称}({代码}) 个股特征表

> 全量快照，每次复盘/分析后整表重写
> 最后更新：{YYYY-MM-DD HH:mm}

## 一、基础信息
| 字段 | 值 |
|------|-----|
| 代码 | {code} |
| 名称 | {name} |
| 行业 | {industry} |
| 持仓状态 | {持仓/关注/验证} |
| 目标仓位 | {x%} |
| 关注逻辑 | {一句话} |

## 二、当前状态判定
| 字段 | 值 |
|------|-----|
| 当前阶段 | {磨底/拉升/出货/横盘/破位} |
| 当日涨跌 | {+x.xx%} |
| 量能状态 | {地量/温和/放量/天量}（换手{x.x%}） |
| 强弱对比 | {强于/弱于} 板块/大盘 |
| 异常标记 | {⭐夹板吸筹 / ⚠️高位破位 / 无} |

## 三、估值锚
| 字段 | 值 |
|------|-----|
| 现价 | {x.xx} |
| PE(TTM) | {x.x} |
| PB | {x.xx} |
| 52周区间 | {低} ~ {高} |
| 估值定性 | {破净/合理/高估} |

## 四、关键价位（结构化）
| 类型 | 价位 | 说明 |
|------|------|------|
| 上方压力1 | {x.xx} | {说明} |
| 上方压力2 | {x.xx} | {说明} |
| 启动位 | {x.xx} | {触发条件} |
| 下方支撑1 | {x.xx} | {说明} |
| 下方支撑2 | {x.xx} | {说明} |
| 止损/失效位 | {x.xx} | {触发条件} |

## 五、主力/盘口特征
| 字段 | 值 |
|------|-----|
| 主力手法 | {夹板吸筹/拉高派发/波段高抛低吸/无} |
| 盘口结构 | {上下夹板/单边压单/单边托单/正常} |
| 关键盘口证据 | {如：上方18.19压2390手，下方18.11托1604手} |
| 启动信号 | {如：压单放量被吃+破18.20} |
| 失效信号 | {如：跌破17.70} |

## 六、股性标签（长期积累，全量保留）
| 标签 | 说明 | 置信度 |
|------|------|--------|
| {波段振幅票/趋势票/情绪票/...} | {说明} | {1-5} |

## 七、历史手法规律（长期积累，全量保留）
- {如：地量磨底1-2月→突然暴力拉升；不主动挖坑洗盘}

## 八、操作建议
| 字段 | 值 |
|------|-----|
| 当前操作 | {BUY/SELL/HOLD/WATCH} |
| 仓位建议 | {轻/中/重} |
| 时间周期 | {短/中/长} |
| 核心结论 | {一句话} |

## 九、更新记录
| 日期 | 触发事件 | 关键变化 |
|------|---------|---------|
| {date} | {复盘/分析} | {本次更新了什么} |
```
