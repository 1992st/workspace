## 二、AI 岗位分类体系

当前 AI 相关岗位可以分为以下几大类：

### 第一类：AI 算法工程师（传统+大模型）

**典型职位名**：算法工程师 · 大模型算法工程师 · NLP/多模态算法

**核心要求**：
- Transformer 架构、模型微调 (LoRA/QLoRA)
- RAG 系统设计优化、推理优化（量化、KV Cache）
- 需要论文（顶会）或落地项目

**薪资**：应届 2.6 万/月，3 年经验 4-5 万/月

**适合度**：❌ 不适合嵌入式背景，偏学术/数据背景

### 第二类：大模型应用开发工程师（增长最快 🔥）

**典型职位名**：AI 应用开发工程师 · 大模型应用开发 · LLM 开发工程师

**核心技能栈**：
```
Prompt Engineering ⭐⭐⭐⭐⭐
RAG ⭐⭐⭐⭐⭐
LangChain / LlamaIndex ⭐⭐⭐⭐
向量数据库 ⭐⭐⭐⭐
Agent / Function Calling ⭐⭐⭐⭐
智能体工作流设计 ⭐⭐⭐⭐⭐
后端开发 (Python/Go) ⭐⭐⭐⭐⭐
```

**面试重点**：
- 如何提升 RAG 检索准确率
- Agent 架构设计（工具调用、规划、记忆）
- 大模型幻觉解决方案
- 评估大模型输出质量

**薪资**：应届 3.0 万/月，3 年经验 5.0 万/月

**适合度**：✅ **非常契合** — 你的 Agent 开发经验完全匹配

### 第三类：AI 产品经理

**典型职位名**：AI 产品经理 · 智能产品经理 · AI 应用产品经理

**核心要求**：
- 理解大模型能力边界
- 能与算法工程师沟通
- 能把 AI 能力转化为用户体验

**薪资**：应届 2.2 万/月，3 年经验 3.8 万/月

**适合度**：🟡 可考虑 — 你做过完整的产品开发流程，但通常要求产品经验/设计背景

### 第四类：嵌入式 AI 工程师（你的独特优势 🔥）

**典型职位名**：嵌入式 AI 工程师 · 边缘 AI 工程师 · AI 嵌入式软件工程师

**代表企业和大致薪资**：

| 企业 | 职位 | 薪资 | 技术要求 |
|------|------|------|---------|
| **大疆** | AI Agent 后端开发 | 30-55K·15薪 | LLM、RAG、MCP、Agent 架构 |
| **塞防科技** | 云端+边缘多智能体 | 30-55K·15薪 | Agent、边缘部署 |
| **AI 玩具企业** | 嵌入式软件（AI 玩具）| 20-40K·15薪 | ARM Linux、C/Python |
| **猎聘汇总** | 嵌入式 AI（边缘视觉）| 25-50K·14薪 | RK3588、边缘推理 |
| **ADI** | AI/ML 工程师 | 面议 | 传感器+AI 融合 |

**核心技能**：
```
嵌入式 Linux ⭐⭐⭐⭐⭐
ARM/SoC 开发 ⭐⭐⭐⭐⭐
C/C++ ⭐⭐⭐⭐⭐
TensorRT/ONNX 部署 ⭐⭐⭐⭐
AI Agent 架构 ⭐⭐⭐⭐⭐
LLM 应用集成 ⭐⭐⭐⭐⭐
端侧推理优化 ⭐⭐⭐⭐
RTSP/音视频处理 ⭐⭐⭐⭐
```

**适合度**：✅ **最契合** — 你的经验直接对标这个方向

### 第五类：AI Agent / 智能体开发（新兴 🔥）

**典型职位名**：AI Agent Engineer · 智能体开发工程师 · MCP 工程师

**2026 年数据**：
- 智能体市场达 135.3 亿元，增速超 70%
- BeBee 上有 215+ AI Agent 职位
- 字节 7 个团队布局 Agent

**核心要求**：
- Agent 框架经验（OpenClaw / LangChain / AutoGPT）
- MCP 协议理解
- Tool Use / Function Calling
- Multi-Agent 协调设计

**适合度**：✅ **非常契合** — 你的多 Agent 协调经验是核心卖点
