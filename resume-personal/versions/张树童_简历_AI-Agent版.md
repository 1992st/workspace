## 项目经验

### 一、AI Agent 多 Agent 协作平台（2025 — 至今）🔑 核心亮点

**关键词**: Multi-Agent 架构 · 记忆系统 · MCP 协议 · 状态监控 · 智能唤醒

独立设计并实现企业级 Multi-Agent 协作平台「Stone」，管理 6 个专业 Agent 的完整生命周期：

- **Agent 工作流引擎**: 任务规划、调度、监控、异常自愈（10 分钟级自适应监控周期）
- **分层记忆系统**: MemoryStore + ContextBuilder，支持 Critical / Operation / Failure 三级记忆，subagent 间上下文继承
- **MCP 协议集成**: Tool Use、Function Calling，打通 Agent 与外部工具的数据通道
- **智能唤醒机制**: Gateway HTTP API 唤醒，Agent 异常中断自动恢复
- **多渠道集成**: 飞书群监控报告推送 + 双向沟通

**技术栈**: OpenClaw Agent Framework, MCP, RAG, LLM (DeepSeek/GPT), Node.js, Python

### 三、录音卡牌开发（物奇 7036 芯片）

**关键词**: DSP 开发 · USB HID/MSC · IPC 通信 · BLE/BT · CPU 调优 · 低功耗

基于物奇 7036 芯片开发智能录音卡牌产品，负责从芯片选型到量产的全流程：

- **DSP 固件开发**: 音频采集、处理、编码全链路自研
- **USB 协议栈**: HID Class + MSC Class 集成，实现 PC/移动端即插即用
- **IPC 通信**: 多任务协同架构，确保录音、传输、控制并行工作
- **无线功能**: BLE/BT 功能开发，支持 OTA 升级和远程控制
- **攻坚重点**: CPU 性能调优 + 低功耗优化，实现长时间稳定录音和语音分离功能
