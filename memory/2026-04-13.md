### 5. Memory Plugin Architecture
- **Source**: `/Users/zhangst/work/code/moltbot/src/plugins/memory-state.ts`, `/Users/zhangst/work/code/moltbot/src/memory-host-sdk/host/internal.ts`, `/Users/zhangst/work/code/moltbot/src/memory-host-sdk/host/types.ts`
- **Plugin model**: Memory is **not hardcoded** in `system-prompt.ts`. It uses a plugin registry:
  - `registerMemoryCapability(pluginId, capability)` — unified registration.
  - `registerMemoryPromptSupplement(pluginId, builder)` —追加 extra prompt snippets.
- **Built-in vs external**: OpenClaw ships with a built-in memory bundled plugin that registers a `promptBuilder` and `runtime` at startup. Users/developers can register additional or replacement plugins.
- **Persistence (落盘) rules** (`listMemoryFiles`):
  1. `workspace/MEMORY.md`
  2. `workspace/memory.md` (fallback)
  3. `workspace/memory/**/*.md` (recursive)
  4. User-configured `extraPaths` (via config)
- **Chunking rules** (`chunkMarkdown`):
  - Splits markdown into chunks based on token budget (with CJK-aware `CHARS_PER_TOKEN_ESTIMATE`).
  - Configurable overlap.
  - Each chunk gets SHA256 hash for incremental sync.
- **Retrieval backend** (`MemorySearchManager`):
  - `builtin`: Uses internal vector index (embedding model required).
  - `qmd`: Delegates to external QMD backend.
  - `sync()`: Re-indexes `MEMORY.md`, `memory/*.md`, and optional `sessionFiles`.
- **Prompt content source**: The actual `## Memory` section text comes from the **registered plugin's `promptBuilder`**, not framework core. Typical built-in prompt instructs: "Mandatory recall step: semantically search MEMORY.md + memory/*.md before answering..."
- **Context Engine relation**:
  - Legacy mode: memory prompt goes directly into base system prompt.
  - New Context Engine (`contextEngine.info.id !== "legacy"`): `includeMemorySection = false`, memory assembly delegated to `assembleAttemptContextEngine()`.

### 6. Default Model Calls for "Organization/Analysis"
- **Context Engine** (`attempt.context-engine-helpers.ts`): Runs `bootstrap`, `assemble`, `afterTurn` / `ingestBatch`. May call embedding model for vector search and LLM for summarization/fact extraction.
- **Auto-Compaction** (`attempt.ts`): pi-coding-agent automatically calls LLM to compress conversation history when approaching token limits. OpenClaw adds 60s aggregate timeout guards.
- **Heartbeat** (`heartbeat.ts`, `heartbeat-summary.ts`): Default every 30 minutes, auto-triggers an LLM run with `HEARTBEAT_PROMPT` to check `HEARTBEAT.md`. Can use a separate `heartbeat.model`.
