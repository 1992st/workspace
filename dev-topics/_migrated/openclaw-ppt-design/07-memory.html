Memory Plugin
promptBuilder + runtime
OpenClaw Core
不硬编码，只预留 slot
设计意图
Memory 对 OpenClaw 框架来说是 透明的——框架只负责调用 Plugin 注册的 builder，把结果拼接进 System Prompt。你可以随时替换内置实现，接入自己的向量数据库或企业知识库。
