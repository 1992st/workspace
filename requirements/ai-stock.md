## 下一步计划

### 优先级1: 检查上周预测结果（立即执行）
1. 读取 `ai_decisions/` 目录中 2026-02-24 至 2026-02-28 的预测记录
2. 使用 akshare 获取对应的实际股价数据（2026-03-02）
3. 对比预测操作（买入/卖出/持有）和实际涨跌
4. 计算准确率、盈亏比等指标
5. 分析错误模式（市场环境变化、板块轮动等）
6. 生成详细的准确性报告

### 优先级2: 优化分析策略 - 引入 LLM 综合分析（核心优化）
**核心问题**: 目前分析过于依赖固化的代码评分，缺乏灵活性

**优化方向**:
1. 审查 `batch_comprehensive_analysis_v3_rational.py` 中的评分逻辑
2. 识别所有硬编码的评分规则（如板块热度、新闻情绪的权重）
3. **关键改变**: 从"代码评分"转向"LLM 综合分析"
   - 技术指标（MA/MACD/RSI）保持代码计算（数据准确）
   - 但最终决策由 LLM 基于多维度信息综合判断
   - LLM 可以理解市场情绪、板块轮动、突发事件等复杂因素
4. 设计 LLM 分析 Prompt 模板：
   - 输入：技术指标、新闻摘要、板块数据、市场环境
   - 输出：综合分析和操作建议（买入/卖出/持有 + 理由）
5. 使用 DeepSeek API 或 GLM API 实现实时分析
6. 逐步替换硬编码的评分逻辑
7. A/B 测试对比新旧系统（LLM 综合分析 vs 代码评分）

**预期效果**:
- LLM 综合分析能够考虑代码难以捕捉的复杂因素
- 提高预测准确率，特别是在市场环境变化时
- 更灵活地适应不同市场情况
