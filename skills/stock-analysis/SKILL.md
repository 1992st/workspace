# 股票分析策略 Skill

## 目标

建立系统化的股票分析框架，结合技术指标、基本面、消息面进行多维度分析，生成可执行的投资建议。

补充定位：
- 本 Skill 也负责吸收新方法并反哺分析体系
- 当任务是阅读投资书籍、整理方法论、复盘后抽象规则时，必须切换到 `prompts/current/book_method_extraction.md`
- 书籍提炼任务的终点是形成 Win_Stock 的方法增量，不是机械读书摘要

## Prompt 使用规则

### 个股/板块/市场分析任务
- 使用 `prompts/current/stock_analysis.md`
- 结合 `prompts/current/investment_rules.md`
- 如果运行时已注入编译后的 book strategies，还要遵守 `prompts/current/compiled/`
- 若正式走 `stock-skill` 分析链路，以上层 `analysis.stock.prepare` 返回的 `compiled_prompt` 为唯一执行约束源；`prompts/current/stock_analysis.md` 需与之保持同语义

### 书籍提炼/方法沉淀任务
- 使用 `prompts/current/book_method_extraction.md`
- 在总结新方法前，必须回看：
  - `prompts/current/investment_rules.md`
  - `prompts/current/compiled/stock_strategy_base.md`
  - `prompts/current/stock_analysis.md`
  - `books/` 下已收录或已归档的方法文档
- 不要求所有新想法立即写成固定规则编号
- 只有成熟度足够高的方法，才进一步进入 `books/*/strategy/registry.json`

## 正式入口

### 入口一：分析任务入口
- 适用：个股分析、板块分析、大盘分析、盘后复盘中的分析结论生成
- 入口 Prompt：`prompts/current/stock_analysis.md`
- 配套约束：`prompts/current/investment_rules.md` + `prompts/current/compiled/`

### 入口二：方法沉淀入口
- 适用：阅读投资书籍、整理交易方法、复盘后抽象规则、比较不同流派方法
- 入口 Prompt：`prompts/current/book_method_extraction.md`
- 配套约束：本 Skill、`investment_rules.md`、`compiled/`、`books/` 索引

### 入口触发条件
出现以下意图之一时，必须走“方法沉淀入口”而不是普通分析入口：
- 用户要求“归档/阅读/提炼”某本投资书或材料
- 用户要求“总结通用方法”“形成自己的分析方法”“沉淀规则”
- 用户要求把复盘经验抽象成方法，而不是只评价某一只股票

### 触发词清单
以下词语或近义表达，默认触发“方法沉淀入口”：
- `归档`
- `阅读`
- `提炼`
- `总结方法`
- `通用方法`
- `形成自己的分析方法`
- `自己的分析方法`
- `沉淀规则`
- `抽象方法`
- `比较流派`
- `方法论`
- `读书笔记`
- `复盘提炼`

### 统一入口边界
- 统一入口的职责只到“告诉 Agent 去哪里找材料、规则和索引”
- 它可以提供路径、目录、索引和相关文档入口
- 它不能替代 Agent 阅读书籍，也不能预先把书籍内容压缩成固定结论再喂给 Agent
- Agent 拿到路径和大纲后，必须自行阅读原始材料或可用提取材料，再参与分析和总结

## 分析层次

### 第一层：大盘环境分析
- 市场阶段判断（牛/熊/震荡）
- 风险偏好评估
- 资金流向观察
- 涨跌家数比
- 优先读取最近有效的 `market-sector-prediction` 大盘预测上下文；缺失或过期时只标注缺口，不阻塞个股分析

### 第二层：板块/概念分析
- 板块热度排行
- 资金流向分析
- 持续性评估
- 龙头股识别
- 优先读取个股所属板块最近有效预测；若板块处于退潮或防御状态，个股进攻性建议必须降置信度

### 第三层：个股综合分析
- 技术面分析
- 基本面评估
- 消息面影响
- 资本行为观察

## 技术分析框架

### 趋势判断
```
1. 均线系统
   - MA5/MA10/MA20/MA60 排列
   - 金叉/死叉信号
   - 均线支撑/阻力

2. MACD 指标
   - DIF/DEA 位置
   - 柱状图变化
   - 背离信号

3. RSI 指标
   - 超买(>70)/超卖(<30)
   - 背离信号
   - 强弱分界(50)

4. 布林带
   - 开口/收口
   - 触碰上下轨
   - 中轨方向
```

### 量价分析
```
1. 成交量趋势
   - 放量上涨（确认）
   - 缩量上涨（警惕）
   - 放量下跌（恐慌）
   - 缩量下跌（筑底）

2. 量比观察
   - >2: 异常放量
   - 1-2: 正常活跃
   - <0.8: 交投清淡

3. 换手率
   - >10%: 高度活跃
   - 3-10%: 正常活跃
   - <3%: 清淡
```

### 支撑阻力识别
```
1. 历史高低点
2. 均线位置
3. 整数关口
4. 前期密集成交区
5. 跳空缺口
```

## 基本面评估框架

### 估值水平
```
PE(TTM):
  - <10: 低估值
  - 10-30: 合理
  - >30: 高估值

PB:
  - <1: 破净
  - 1-3: 合理
  - >5: 高估值

PEG:
  - <1: 性价比高
  - 1-2: 合理
  - >2: 高估
```

### 成长性
```
营收增长率:
  - >30%: 高增长
  - 10-30%: 稳健增长
  - <10%: 成熟/衰退

净利润增长率:
  - >50%: 爆发增长
  - 20-50%: 良好
  - <20%: 一般
```

### 财务健康
```
ROE:
  - >15%: 优秀
  - 10-15%: 良好
  - <10%: 一般

负债率:
  - <50%: 安全
  - 50-70%: 关注
  - >70%: 高风险

现金流:
  - 经营现金流为正
  - 自由现金流充裕
```

## 资本行为分析

### 主力资金识别
```
1. 大单资金流向
   - 连续多日净流入
   - 突然大额流入
   - 尾盘抢筹/砸盘

2. 龙虎榜分析
   - 机构席位动向
   - 游资席位风格
   - 买卖金额对比

3. 筹码分布
   - 筹码集中度
   - 获利盘比例
   - 套牢盘位置
```

### 高阶资金/交易数据使用规则
```
1. 券商ETF PCF / 申购赎回相关
   - 用于判断板块 beta 资金关注度
   - 不能把 PCF 清单误判成盘中实时净申赎

2. 融资融券余额变化
   - 看变化方向，不只看绝对值
   - 价格上涨 + 融资余额提升：趋势强化但拥挤风险上升
   - 价格下跌 + 融资余额回落：去杠杆风险

3. 沪股通十大活跃股
   - 看外资是否认可主线和龙头
   - 个股或同板块核心股进入前十且净买额为正，才增强结论

4. 龙虎榜
   - 先判断是否上榜，再区分机构/北向/游资席位
   - 纯游资主导时，持续性和次日分歧风险更高

5. 大宗交易
   - 看折价率、交易对手、连续性
   - 单笔记录不能直接下利空或利好结论
```

### 操盘手法识别
```
1. 洗盘特征
   - 快速下跌后快速收回
   - 缩量下跌
   - 关键位置有支撑

2. 出货特征
   - 高位放量滞涨
   - 利好不涨
   - 分时图锯齿状

3. 吸筹特征
   - 低位横盘放量
   - 阳线多阴线少
   - 尾盘拉升
```

## 分析流程
### 数据需求与降级
- 先识别本次属于 `Scan / Standard / Deep / Review` 哪种分析类型
- 对照 `references/data_requirements_spec.md` 检查必须项和建议项
- 该文档不仅是运行时配置来源，也属于分析思路的一部分，必须进入分析前置判断
- 必须项缺失时先补数；补不到则降级分析，而不是假装完成原级别分析
- 分析输出必须先声明：
  - 分析类型
  - 数据完整度
  - 置信度上限
  - 降级原因（如有）
- 不再把 `scripts/analysis_gate.py` 作为“不过门就拒绝分析”的正式主流程；它仅作为辅助诊断工具

### 反证与偏差检查
- 每次分析都必须显式写出最强反证
- 必须检查：
  - 是否只用了极短时间窗
  - 是否只用了单一维度
  - 是否用叙事替代了数字证据
  - 是否把别的股票框架直接套在当前标的上

### 个股档案使用
- 若存在 `data/watchlist/active/{code}/profile.md`，分析时应优先读取：
  - 关键价位及确认次数
  - 股性特征
  - 最近分析历史
- 这些内容属于“历史记忆”，可以辅助修正近因偏差，但不能替代本次实时数据

### 财报方法资源
- `references/financial_analysis_resources.md` 必须作为分析思路辅助资源动态读取
- `Standard` 以上分析若已具备估值或基本财务数据，应参考其中的财报健康度、盈利质量、风险识别、估值判断框架
- 财报方法资源不能替代市场、板块、资金证据，但必须能进入基本面判断和反证部分

## 方法沉淀最小输入

进入“方法沉淀入口”时，至少要向 Agent 暴露这些路径或索引：
- 当前任务涉及的原始材料路径
- 相关 `books/` 历史归档路径
- `prompts/current/investment_rules.md`
- `prompts/current/compiled/stock_strategy_base.md`
- `prompts/current/stock_analysis.md`

说明：
- 这些输入是“入口提示”和“材料定位”，不是替代阅读的摘要包
- 如果原始材料可读，Agent 应优先阅读原始材料
- 如果原始材料不可直接消费，再使用提取文本、EPUB、历史笔记等辅助材料

## 注意事项

1. **客观性**: 基于数据，避免主观臆断
2. **完整性**: 所有维度都要覆盖，不能只看技术面
3. **时效性**: 使用最新数据，过期数据要标注
4. **一致性**: 同一股票的分析标准保持一致
5. **可追溯**: 所有分析必须存档，方便复盘
