# 股票分析策略 Skill

## 目标

建立系统化的股票分析框架，结合技术指标、基本面、消息面进行多维度分析，生成可执行的投资建议。

## 分析层次

### 第一层：大盘环境分析
- 市场阶段判断（牛/熊/震荡）
- 风险偏好评估
- 资金流向观察
- 涨跌家数比

### 第二层：板块/概念分析
- 板块热度排行
- 资金流向分析
- 持续性评估
- 龙头股识别

### 第三层：个股综合分析
- 技术面分析
- 基本面评估
- 消息面影响
- 资本行为观察

## 技术分析框架

### 趋势判断
```
1. 均线系统
   - MA5/MA10/MA20/MA60 排列
   - 金叉/死叉信号
   - 均线支撑/阻力

2. MACD 指标
   - DIF/DEA 位置
   - 柱状图变化
   - 背离信号

3. RSI 指标
   - 超买(>70)/超卖(<30)
   - 背离信号
   - 强弱分界(50)

4. 布林带
   - 开口/收口
   - 触碰上下轨
   - 中轨方向
```

### 量价分析
```
1. 成交量趋势
   - 放量上涨（确认）
   - 缩量上涨（警惕）
   - 放量下跌（恐慌）
   - 缩量下跌（筑底）

2. 量比观察
   - >2: 异常放量
   - 1-2: 正常活跃
   - <0.8: 交投清淡

3. 换手率
   - >10%: 高度活跃
   - 3-10%: 正常活跃
   - <3%: 清淡
```

### 支撑阻力识别
```
1. 历史高低点
2. 均线位置
3. 整数关口
4. 前期密集成交区
5. 跳空缺口
```

## 基本面评估框架

### 估值水平
```
PE(TTM):
  - <10: 低估值
  - 10-30: 合理
  - >30: 高估值

PB:
  - <1: 破净
  - 1-3: 合理
  - >5: 高估值

PEG:
  - <1: 性价比高
  - 1-2: 合理
  - >2: 高估
```

### 成长性
```
营收增长率:
  - >30%: 高增长
  - 10-30%: 稳健增长
  - <10%: 成熟/衰退

净利润增长率:
  - >50%: 爆发增长
  - 20-50%: 良好
  - <20%: 一般
```

### 财务健康
```
ROE:
  - >15%: 优秀
  - 10-15%: 良好
  - <10%: 一般

负债率:
  - <50%: 安全
  - 50-70%: 关注
  - >70%: 高风险

现金流:
  - 经营现金流为正
  - 自由现金流充裕
```

## 资本行为分析

### 主力资金识别
```
1. 大单资金流向
   - 连续多日净流入
   - 突然大额流入
   - 尾盘抢筹/砸盘

2. 龙虎榜分析
   - 机构席位动向
   - 游资席位风格
   - 买卖金额对比

3. 筹码分布
   - 筹码集中度
   - 获利盘比例
   - 套牢盘位置
```

### 操盘手法识别
```
1. 洗盘特征
   - 快速下跌后快速收回
   - 缩量下跌
   - 关键位置有支撑

2. 出货特征
   - 高位放量滞涨
   - 利好不涨
   - 分时图锯齿状

3. 吸筹特征
   - 低位横盘放量
   - 阳线多阴线少
   - 尾盘拉升
```

## 注意事项

1. **客观性**: 基于数据，避免主观臆断
2. **完整性**: 所有维度都要覆盖，不能只看技术面
3. **时效性**: 使用最新数据，过期数据要标注
4. **一致性**: 同一股票的分析标准保持一致
5. **可追溯**: 所有分析必须存档，方便复盘
